## 1. 安装、升级与个人资料

### Windows教师试用

在本版Release下载 `ShanghaiChem-0.1.101-Windows-x64.zip`，先关闭旧版，**完整解压**后双击 `沪上化学智研台.exe`。无需另装Python；不要在压缩包里直接启动，不要只拷贝EXE，不要删除旁边的`_internal`。状态栏应显示 **v0.1.101／打包版**。

程序尚未数字签名，发布为预发布试用包。核对本仓库Release来源与`SHA256SUMS.txt`，不要关闭Windows防护。独立目录运行检查不代表全部学校受管电脑、所有Windows版本或多屏配置均已验证。

实际试卷分页预览需要本机 **LibreOffice 或 Microsoft Word**。程序不附带这些软件。缺少Office转换工具时，题库、题篮、草稿和已有评分不因此清空；PDF分页相关功能会提示缺项。

### 开发源码

使用Python3.12，在仓库根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r runtime\deeptutor_shchem\desktop_requirements.txt
```

然后双击根目录的 **`启动源码桌面版.cmd`**。已有Git工作区先保存未提交修改，再 `git fetch origin`、`git switch feature/lesson-source-0.1.101`；复现已发布代码可另建分支 `git switch -c trial-0.1.101 v0.1.101`，不要强制重置本机工作。旧VBS可能仍打开旧EXE；源码无法启动时运行 **`检查运行环境.cmd`**。

### 资料放在哪里

个人桌面状态默认在 `%LOCALAPPDATA%\ShanghaiChem\DesktopWorkbench`。程序目录与个人资料分开；换程序版本不会自动复制另一源码目录旁的私有题库。原工作区可按现有规则通过`SHCHEM_WORKSPACE_ROOT`关联，不把题库放进`_internal`。

本程序包**不包含原教材、用户题库、学生作答、API密钥、Office或字体文件**。初装空题库不是下载损坏。学生作答、批次和批改暂存沿用学生业务私有目录，与备课草稿区分；现有备课ZIP尚不包含学生业务。

## 3. 五条常用工作流程

**把已有试题变成一张卷：** 导入资料并核对题答范围 → 补标签 → 选题入篮 → 调整题序与配分 → 必要时修改扫描图题号 → 检查学生/教师两版真实PDF → 导出。

**备好一节课：** 从模板或现有课题开始 → 添加实际材料与教学目标 → 核对发送范围并生成初稿 → 从已有初稿加入教学环节 → 教师核对活动、目标与材料范围 → 同源生成教案/PPT/学习单 → 实际预览与导出 → 保存草稿并备份登记成品。也可不调用模型，直接手写环节。

**复核一个学生：** 学生分析中打开作答 → 确认题目、学生作答与答案页的匹配 → 生成或读取已有分析 → 同屏查看原页与建议 → 教师记录评分及诊断 → 按已有标签寻找复练题。

**连续批改多人：** 学生分析 → 作业批次 → 新建批次并明确选择每名学生的一份已有作答 → 逐人/逐题核对 → 正式记录分数，未完成输入可暂存 → 标明待核对或缺页等情况 → 下次重新打开继续。可用“正式评分统计”查看同一原题组的已确认结果；不自动完成所有学生的模型分析，也不混排不同试卷。

**从一次考试安排复练：** Excel考试分析或作业批次正式评分统计 → 选失分题及学生、填写可检查目标 → 去真实题库按标签选题 → 返回任务勾选专用题目 → 预览并导出两版练习卷 → 学生实际作答后记录日期、分数/缺失情况 → 导出含复测记录的报告。

## 5. 选题中心：左侧标签，右侧原题

![选题中心与完整题面；0.1.95实际合成验收截图](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.95/explorer-loaded.png)

先在左侧选择实际拥有的资料来源，再使用来源支持的教材、章节、知识点、年级或考试类型筛选。**同类满足任一条件，不同类同时满足**；删除顶部标签可单独取消一个筛选。来源选择会记住，空结果可切换已导入Word或图片题，不把空原卷目录误当所有库都没有题。

右侧题卡可展开题面、公共材料与图片，并切换答案/解析。核对后加入题篮，已加入状态不会因翻页丢失。题篮中的一项可能是带多个小问的完整主题，不等于一条最小作答单元。依赖共同材料或前题条件的小问不作为缺条件孤题导出。

个人目录首次读取后建立可丢弃索引；同来源最多缓存四组匹配结果，后续筛选/翻页复用。Word同标签页多图合并读取，答案按需展开；不通过降低原图质量换速度。导入、标签管理和“重新读取”会更新快照；外部直接修改来源文件后需手动重新读取。

左侧“复制加载记录”只复制各阶段耗时和数量，不含关键词、题面、路径或密钥。首次大目录、旧公式转换、大图解码和外部磁盘仍可能慢，局部性能数字不是全库冷启动承诺。

## 6. 题篮、组卷与连续题号

![原生组卷页面；0.1.94历史实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.94/packaged-paper.png)

题篮可查看、上移、下移和移除，移除不删除原题。**“预览试卷排版”使用当前题篮；“进入组卷编辑”继续组卷草稿**，两者不要混为同一范围。混合组卷编排Word原题与图片主题，保留完整共同材料、已有公式和作答区域。

教师可调整卷名、用时、题序、配分与当前编辑页支持的作答设置。未知分值需要核对，不能作为确定的0分。原题已有横线、表格或绘图区时不重复添加。生成后切换学生版/教师版逐页检查，确认后导出本次核对的同一批文件；调整题序后重新生成预览。

### 文字题号与图片题号

可编辑文字题号按本卷顺序重新编号，对应答案同步；同来源且对应唯一的文字引用跟随更新。题内(1)(2)层级、选项、公式上下标及12.5等数值不做粗暴数字替换。教师来源说明保留原题号，便于回查。

![图内编号区域复用；0.1.94实际合成验收截图](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.94/scan-reused-regions.png)

扫描图片内部的旧号在混合组卷 **“调整图片题号后预览…”** 中处理。选图，只框旧号，填写本卷号码并添加替换；可原图对照、撤销、移除或清除。修改写入学生/教师DOCX副本，再进入实际PDF转换，不只是窗口遮盖。原图不改写，框外像素保留。

“记住此图位置”只存原图身份、尺寸和坐标，不保存旧卷新号码；下次“载入位置”后核对当前号再应用。能唯一对应一条Word印刷题时提供本卷号码建议，共享材料或多义对应不猜。图内“见第N题”等引用须另核对目标。

当前限静态PNG/JPEG/BMP白底数字方式；彩底、旋转、同图不同实例需要不同编号和复杂跨页来源仍有待补齐。答案标题/短首段与首内容块关联分页，长答案不强制挤在一页。编号正确不代表所有复杂卷面已终验。

## 7. 学生分析、同屏批改与作业批次

### 上传、匹配和分析

学生以已有匿名代号管理。按当前界面选择原题、学生作答、参考答案页，先在本机准备并核对页码对应和满分，再确认需要发送的材料及模型。资料不足、匹配不明或模型不支持图片时，不应把文本联通当作识图通过。

已有分析可重新打开，不需要重新收费调用。原作答、模型建议和教师决定分别保存；“不能据此判错”的信息不是已确认的0分。真正模型识别准确率取决于所选模型、页面质量和人工核对，本版合成测试不构成准确率证据。

### 一份作答的同屏复核

打开已有分析后，点击顶部 **“打开作答与评分（同屏批改）”**。左侧选题，中间切换学生作答、原题/公共材料和参考答案，右侧分为“教师评分”与“AI建议”。支持适合宽度、整页、缩放和拖动；AI证据框需对应实际页面，框线不修改原图。

## 考试数据分析：成绩Excel＋试卷＋API讲评

**入口：学生分析 → 考试分析（Excel）**，或按`Ctrl+K`搜索“考试分析”。这是已有原生工作台内的考试面板，不需要搭建Web服务器。图表用本地确定性统计，API仅生成讲评和行动建议，不执行模型返回的HTML或代码。

### 1）导入、映射和检查

![成绩列、题号与真实满分映射；0.1.98合成验收](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.98/exam-import.png)

点击“保存Excel示例”可取得含**成绩／题目映射／使用说明**三张表的xlsx。示例全为合成数据，请替换为自己的一场考试：一行一名学生、唯一学号或标识、一列总分及可选逐题得分；不要夹带合计/均分行或多场考试。也可直接使用自己的普通xlsx，不强制套模板。

选择工作表与真实表头行，映射学生、班级、总分及可选缺考状态列；明确试卷满分、达标线和高分线。默认100/60/85只是可修改的分析参数，不是上海等级考官方赋分标准。学号数字的显示格式不等于原始值，前导零请在Excel以文本保存。

有小题分数时，在第二页勾选对应成绩列，填写本卷题号、**真实满分**、单一主知识点、章节和公共材料说明。可读取“题目映射”工作表，但需要教师核对。不能从最高实得分猜满分，也不能同时勾大题总分和所属小问；按题目加总时必须映射全部非重叠评分单元且满分之和吻合。不自动生成未经核对的知识点映射。

**只有总分仍能用**，但不生成逐题/知识点掌握结论。空白、未批和缺考不当0分；负分、超满分、Excel错误、未缓存公式等进入“数据核对”。完整小题合计与总分冲突时排除该行总分，保留有效小题并指出冲突。重复学生标识会要求先修正，不静默合并。

公式只读Excel已经保存的计算结果，不运行宏或重算公式；缓存可能过期，导入前请在Excel重算并保存。隐藏行/筛选行也会读取。仅支持普通`.xlsx`，不支持旧`.xls`、加密文件和宏表。每表最多10000行、256列、最多映射200个评分单元；超范围请按同场考试/班级拆分。

### 3）添加试卷，再让API生成讲评草稿

![试卷正文、API选择与讲评草稿；0.1.98](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.98/exam-api.png)

### 4）保存、导出和带入备课

“导出可视化报告”生成带SVG图表、指标、题目/学生明细和建议的离线HTML，无远程脚本。导出时可选择保留本机学生标识或临时代号，自由文字仍请自行检查；它不是Excel文件备份。“带入备课材料”追加当前统计摘要和讲评草稿，不覆盖原材料、不自动调用模型或制作PPT，返回备课页核对并保存。

## 评分—复练—复测：让分析有后续动作

### 1）从已有作答读取正式评分，不再手抄一份Excel

**学生分析 → 作业批次 → 打开批次 → 正式评分统计 → 选择同卷组。** 当前在编辑的内容先按原规则暂存；统计只读取已点击“记录本题评分”的教师决定，不把暂存或模型建议当得分。

![同卷组正式评分进入考试面板；0.1.99合成验收](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.99/closure-batch-stats.png)

只有原题页内容、题号、满分和答案来源一致的作答单元才合并；不同试卷拆成不同组。未评分、待核对、缺页、未作答、尚未学到、图像难辨不按0分填补。已记录“时间不足”且仍有有效正式分数的作答保留分数，教师可继续核对。

这是**所匹配评分单元的只读快照**，不保证覆盖完整原试卷。快照保留批次、原作答及评分版本；正式改分后再次从批次生成统计，旧快照不会自动悄悄变化。60%/85%仅默认分析参考线，不是上海官方等级划分。知识点留待核对，不从分数反推知识掌握。

### 2）明确复练对象和目标

在考试分析的 **“复练与复测”** 标签中，选择有逐题映射的考试题目，点击“建立复练任务”，勾选该题有有效成绩的学生，填写一个可检查的学习目标和计划日期。只有总分或该题缺失的学生需要先补充证据，不能凭空建立“已经失分”的结论。

![目标、所选学生与实际复测进度；0.1.99合成验收](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.99/closure-panel.png)

任务随本场考试保存，可以从“打开历史分析”继续。考试内的S编号仍不能自动等同另一场Excel的S编号；本版不按名字猜合并学生档案。

### 3）使用原有选题中心，不生成假的推荐题列表

点击 **“去题库按标签选题”**，选本地Word或个人图片来源，再从该来源实际存在的有效知识标签中确认对应。考试标签与题库标签不会不经核对直接视为相同；没有有效标签或没有匹配结果会明确提示。

![保留完整原题、来源与原题篮的选题衔接；0.1.99](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.99/closure-library.png)

回到原有左标签/右题面的选题中心，保留原题阅读器、答案与公共材料。查看后入篮，再点击上方 **“返回复练任务”**；不需要复制题文或另建题库。普通安装缺少私有教材目录时，仍可使用已有K01—K19基本知识分类，但不会编造教材章节。教师本地已安装目录损坏时仍提示修复，不静默覆盖。

### 4）只编排本任务选中的题目

返回后点击 **“关联题篮中的题”**，只勾本任务要用的项目。全局题篮里为其他班级或课程准备的题不会自动混进来；新卷只使用这些明确关联项的顺序。原题篮及旧组卷草稿保留。

**“预览本任务练习卷” → 查看学生/教师两版真实PDF → 确认 → “导出已核对练习卷”。** 导出使用原有组卷链，记录本次题目引用和文件位置，不只是产生一份练习方向文字。题目移出题篮或修订发生变化后，重新关联、核对再预览，不悄悄换题。

![本任务学生/教师两版实际排版核对；0.1.99合成验收](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.99/closure-preview.png)

当前任务预览不额外提供图内题号调整窗口：图内旧号仍需核对，复杂扫描题可回原混合组卷流程处理。没有将所有历史图号功能冒称已自动接入这个新入口。

### 5）学生做过之后，再记实际复测

点击 **“记录实际复测”**，选择任务中的学生，填写真实日期、已作答/未作答/资料不全；已作答时明确实得分、实际满分和观察依据。实际日期不可填未来；未作答和资料不全不记为0分。

![800×700保留任务记录阅读区；0.1.99实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.99/closure-retest.png)

记录以追加方式保存并保留当时的题目引用；当前概况使用每生最新录入的记录，旧记录仍在保存文件中。原考试和复练题不一定等值，**不直接相减宣称提升了几分**；任务完成也不代表知识已经永久掌握。导出可视化报告时会追加当前班级范围内的复测记录，姓名开关不自动清除教师自由文字中的个人信息。

### 6）哪些仍未完成

本轮补的是人工可核对的关联和实际结果，不是全功能已闭环：自动诊断选题排序、跨考学生身份、跨卷量尺对齐、自动批量分析、原作答附件式复测、全业务备份仍待实现。备课建议单向带入已可用，教案/PPT/学习单已能由同一教学设计重新生成；局部页增量刷新与外部改稿回写仍未完成。逐项见[当前联动审查与补充验收项](https://github.com/2067169120-png/shanghai-chemistry-teaching-agent/blob/faf06d36ed13ebea40800f35b36efdcac4e52636/docs/WORKFLOW_STATUS.md)。

## 8. 备课、教案与PPT

![备课固定操作区；0.1.94历史实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.94/scale-1-typography-compact.png)

填写课题、授课对象、课型、课时、教学目标与实际材料，再选择当前任务支持的输出类型。顶部可定位教学要求、备课资料、进度与结果；底部保存/生成保持可达，不必滚到表单最末寻找按钮。

## 教学环节：从同一设计生成教案、课件与学习单

入口：**备课/PPT → 固定操作区“教学环节”**。先在原备课页填写课题、授课对象、课时、目标和资料，随后打开教学设计。仍使用原草稿、个人目录和自动恢复副本；不需要模型配置，不额外导入题库。

![教学环节与目标评价；0.1.100 Windows合成验收](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.100/lesson-design-editor.png)

### 把已生成的初稿转成可编辑教学环节

点击左侧 **“从已有初稿加入…”** → 在当前作品或已归档作品中按课题查找 → 选择一份已完成初稿 → **“读取所选初稿并预览”** → 勾选要加入的环节 → **“加入勾选环节”**。可以使用既有API生成稿，也可以使用原本地修订流程完成的稿件；本次转换不重新调用API、不覆盖原稿，也不替换已经手写的环节。

![已有初稿的教学结构、材料与教师核对；0.1.101 Windows合成验收](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.101/lesson-import-preview.png)

优先按原稿教学阶段组织，带入对应教师活动、学生任务、目标、评价证据和预计用时；未归属阶段的活动及独立PPT页会单独列出，避免静默丢失。独立页面不会因为有正文就被当成学生练习。原页正文保留为教师参考材料，原讲稿、课后安排和不确定事项保留在备注，原稿文件不改动。多环节共用原页时可能重复引用，教师可进一步整理。

**转换不是照搬原PPT版面。** 原图表结构仅保留教师参考，不自动重建成可编辑表格或化学结构图；原稿版式仍可从原任务核对。新环节初设为“解释与建模”，目标关联均待核对，材料和图片默认锁定且仅教师可见。确认任务、答案隔离和作用后再启用学生材料；不能把模型生成状态当成教师确认。

只有勾选环节需要的目标和图片会加入；完全相同的目标文字复用既有目标，不根据相似词自动合并。同一任务、同一原稿版本的已加入环节会提示“已加入”；转换可撤销，原题库、原任务和已有成品不变。新增图片仍存于原备课素材区，撤销环节不会删除素材。若原稿或当前设计在预览后变化，重新读取再确认，不将旧预览强行写回。

随后核对并编辑环节 → 生成教案/PPT/学习单 → 核对实际PPTX → 保存草稿 → 按下方步骤备份三类成品。这个流程已接通原初稿和本地环节，不需要再次抄录全部内容；AI直接按指定环节修订仍待后续接通。

### 按课堂进程编辑，而不是把题目逐页堆放

左侧安排课前诊断、观察与提问、解释与建模、例题讲解、独立练习和反馈小结。支持新增、删除、上下调序、撤销与重做；每个环节保留自己的稳定标识。右侧按“任务与活动／目标与评价／材料与备注”切换，底部的保存、生成、实际预览和返回保持固定。窄窗口继续使用页签，不把全部表单无限向下叠加。

每个环节可填写教师活动、学生任务、预计用时、关联目标、预期产出、评价依据、教师答案和备注。未估时单独计数，不自动记作零分钟或按总课时平均分配。超过计划时长会提示，不阻止保存未完成草稿。

### 目标覆盖需要明确的任务与证据

在“目标与资料”中逐条维护可观察目标；在环节“目标与评价”中勾选对应目标，填写学生任务、预期产出和评价依据，教师核对后勾选确认。状态分为**未安排／待核对／已明确关联**，不是学生掌握度或AI自动评价。

![两个目标中尚有一项未安排；0.1.100实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.100/lesson-goal-gap.png)

例如同时设“用速率判断平衡”和“写出平衡常数表达式”，只安排判据题时，第二项目标仍显示未安排。新增明确对应的表达式任务后才改变其状态。修改目标、活动、学生任务、材料或评价依据会使关联待核对；不会因为同属一个粗知识标签就显示全部覆盖。

### 原题材料与教师答案保持分工

“引用当前备课资料（完整内容）”把当前原文与图片标识引用到所选环节，保留内容摘要并锁定。**默认只供教师查看**：其中可能同时包含原题和答案。需要用于学生页时，先解锁，核对题目与公共条件完整、答案已分离，再勾选“材料和勾选图片用于学生页”。这不是自动题答切割，不要把含教师答案的混合文本直接公开。

锁定后不能修改材料正文、教师答案、图片及其可见范围；仍可以改讲解、学生任务和备注。恢复锁定需要明确操作。原Word和原图不改变，材料引用是本次备课快照，不自动随外部文件更新。本文本快照不是Word全部复杂公式/表格的保真转换；需保真原卷的题目继续使用既有组卷链。

### 一次生成三类可编辑文件

“生成教案 / PPT / 学习单”从同一有序环节生成：`lesson_plan.docx`、`lesson_presentation.pptx`、`student_worksheet.docx`。教案包含目标、活动、评价、材料图和教师说明；投影正文显示学生任务及明确选入的材料；教师答案只写入教案和PPT讲者备注；学习单不写教师答案，也不额外叠加横线。**PPTX含教师备注，不等于可直接发给学生的匿名文件。**

![同源输出与变更提示；0.1.100实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.100/lesson-linked-outputs.png)

内容修改后，输出页会提示“三类输出需更新”，原文件仍保留为旧版本。再次生成创建新目录并自动选中最新版本；手动选旧版时会显示“历史内容”，不会用最新状态误导旧稿。可选择历史输出打开，不覆盖之前文件。

点击“导出所选版本的三类文件…”选择文件夹，程序新建独立副本目录并附文件校验清单；不会覆盖同名旧稿。在Office中修改副本不影响工作台保留的原版本，也不自动回写教学环节。教案和PPT备注含教师答案，请分别发放教师稿与学习单。这一版是重新生成整套文件，不是只渲染受影响页面；外部Office改稿不会反向同步到节点。

### 核对实际PPTX，而不是只看结构图

“核对实际PPTX”读取已经生成的PPTX，经本机LibreOffice Impress转成PDF，在原生窗口中逐页查看，也可打开完整PDF。窗口明确标注引擎。缺少LibreOffice时可继续编辑、保存和打开PPTX，但不能把快速PNG冒充实际预览。**本功能当前不使用PowerPoint COM，也未验证所有Office版本完全一致。**

![由实际PPTX转换的预览；0.1.100合成材料](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.100/lesson-actual-pptx.png)

### 保存、恢复与仍未完成的部分

点击“保存草稿”把环节、目标及输出版本记录写入原备课草稿；返回时刷新原自动恢复副本，旧版无节点草稿仍可读。节点数据随原备课草稿备份。**0.1.101起勾选“包含已结束任务与成品”时，会同时打包已保存草稿或恢复副本中登记的教案、PPT和学习单**，同一成品多处引用只复制一次。恢复后可从原版本记录打开三类文件，并重新生成实际PPT预览；预览缓存不打包。未勾选、原文件缺失或被修改时有明确清单/提示，不把仅存引用称为文件已恢复。新成品路径扩展需0.1.101或后续支持版本恢复，旧备份仍可读取。

原AI初稿生成与逐项修订入口继续保留，但本版新增节点编辑不自动调用API，**不声称已完成AI局部改写并锁定原题的全流程**。当前材料按教师明确引用，不是题库对象到教学节点的自动绑定；已有AI初稿可通过上方入口预览并转换；复杂图表和学生可见范围仍需教师整理。结构化表格/公式、自动题目匹配、PPT母版模板、逐页局部刷新及学生反馈自动回写继续待办。未完成草稿可保存；学生可见文字过长或图片缺失会定位具体环节，不静默截断后交付。

## 13. 模型设置、字体与本机检查

![基础连接设置；0.1.94历史实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.94/settings-basic.png)

填写服务商、Base URL、实际模型名、API密钥与接口格式后保存。高级预算默认收起，已有参数仍保留，留空使用原默认策略；预算不是厂商容量或计费保证。

保存配置只改本机记录；测试连接会另行确认并发送固定短文本。修改配置后旧成功记录不代表新配置已验证。**允许发送图片、模型宣称支持图片、实际读图质量通过是三件不同的事**。文本API不可因能聊天而被当作已具备视觉解析、化学图识别或结构化输出能力。

![中文和化学符号检查；0.1.94历史实际窗口](https://raw.githubusercontent.com/2067169120-png/shanghai-chemistry-teaching-agent/v0.1.101/docs/screenshots/v0.1.94/scale-1-typography-sample.png)

界面优先使用本机实际可用中文字体，正文11磅、部分辅助字9.5磅，并保留化学上下标和箭头的字符回退。`Microsoft YaHei UI`是微软雅黑的英文名称，不代表用英文字体画汉字。界面修复不修改原图片、Word、PPT或PDF字体。

## 14. 常见问题与快捷入口

| 现象 | 处理方法 |
| --- | --- |
| GitHub默认首页和本机版本对不上 | 本页介绍发布版，main应用源码尚未合入全部后续功能；从明确版本Release下载，开发时核对分支与状态栏 |
| 找不到自由拖拽画布 | 0.1.102仍是本地候选，不在v0.1.101内；不要反复重装或重导题库 |
| 更新后还是旧版 | 确认运行新解压目录的EXE或源码启动脚本，查看状态栏版本，不沿用可能指向旧版的VBS |
| 明明导入过，选题却为空 | 切换到对应的本地Word/个人图片来源，清掉过窄标签并重新读取；查看导入实际保存结果 |
| 点击题目仍慢 | 用“复制加载记录”区分目录/索引、题图和卡片阶段；大文件首读与复杂公式仍有成本 |
| 新卷出现旧题号 | 可编辑文字重新生成预览；扫描图使用图内换号入口，图内引用另核对，旧成品不会自动改写 |
| 新批次里无法复核某生 | 批次只分组已有作答；该生尚未完成分析时需回学生分析完成原流程，不会自动调用模型 |
| 切换后分数栏恢复了但统计未变 | 恢复的是暂存输入，正式分数须点击“记录本题评分”；未评分不是0分 |
| 缺页状态和已记录分数同时存在 | 状态与评分独立，教师需核对是否修订分数；软件不会自动删分或判零 |
| 暂存失败无法切换 | 当前输入仍在，先检查本地可写性；记录冲突需重新读取后核对，不会写到其他学生 |
| 恢复备课后没有题库或学生作答 | 备课ZIP并非全工作台迁移，原题库与学生业务当前不包含 |
| 成绩图表没有小题或知识点 | 只有总分或没有明确映射时不虚构分析；在导入页勾选非重叠小题列并填真实满分/知识点 |
| 公式分数未读到 | 先在Excel重算并保存；无缓存不记0分，当前软件不执行Excel公式 |
| 文本API无法分析扫描试卷 | 用支持视觉的模型并明确允许图片发送，或粘贴已核对的题目文字；总分统计不需视觉API |
| 从题库回来后找不到复练题 | 在任务中点“关联题篮中的题”明确勾选，题篮备选项不会全部自动带入 |
| 复测记录已有分数但没显示提分 | 原题和复练题未必等值，程序仅保存实际日期与分数，不把两次不同题的差值当学习增益 |
| PPT预览好看但Office打开不同 | 快速预览不是实际Office渲染；检查字体、换行、上下标与最终投影效果 |

`Ctrl+K`搜索功能，`F1`打开帮助，`Ctrl+1`至`Ctrl+5`切换原五个主页面。窗口常用操作使用完整中文用途，不需要输入后台ID。
