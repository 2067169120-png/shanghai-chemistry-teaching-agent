## 1. 安装、升级与个人资料

### Windows教师试用

在本版Release下载 `ShanghaiChem-0.1.99-Windows-x64.zip`，先关闭旧版，**完整解压**后双击 `沪上化学智研台.exe`。无需另装Python；不要在压缩包里直接启动，不要只拷贝EXE，不要删除旁边的`_internal`。状态栏应显示 **v0.1.99／打包版**。

程序尚未数字签名，发布为预发布试用包。核对本仓库Release来源与`SHA256SUMS.txt`，不要关闭Windows防护。独立目录运行检查不代表全部学校受管电脑、所有Windows版本或多屏配置均已验证。

实际试卷分页预览需要本机 **LibreOffice 或 Microsoft Word**。程序不附带这些软件。缺少Office转换工具时，题库、题篮、草稿和已有评分不因此清空；PDF分页相关功能会提示缺项。

### 开发源码

使用Python3.12，在仓库根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r runtime\deeptutor_shchem\desktop_requirements.txt
```

然后双击根目录的 **`启动源码桌面版.cmd`**。已有Git工作区先保存未提交修改，再 `git fetch origin`、`git switch feature/teaching-closure-0.1.99`，不做强制重置。旧VBS可能仍打开旧EXE；源码无法启动时运行 **`检查运行环境.cmd`**。

### 资料放在哪里

个人桌面状态默认在 `%LOCALAPPDATA%\ShanghaiChem\DesktopWorkbench`。程序目录与个人资料分开；换程序版本不会自动复制另一源码目录旁的私有题库。原工作区可按现有规则通过`SHCHEM_WORKSPACE_ROOT`关联，不把题库放进`_internal`。

本程序包**不包含原教材、用户题库、学生作答、API密钥、Office或字体文件**。初装空题库不是下载损坏。学生作答、批次和批改暂存沿用学生业务私有目录，与备课草稿区分；现有备课ZIP尚不包含学生业务。

## 3. 五条常用工作流程

**把已有试题变成一张卷：** 导入资料并核对题答范围 → 补标签 → 选题入篮 → 调整题序与配分 → 必要时修改扫描图题号 → 检查学生/教师两版真实PDF → 导出。

**备好一节课：** 从模板或现有课题开始 → 添加教材、Word内容、完整题目与教学目标 → 核对发送范围 → 生成初稿 → 检查教学顺序、解释、例题和作答活动 → 修订 → 导出教案/PPT并保存作品。

**复核一个学生：** 学生分析中打开作答 → 确认题目、学生作答与答案页的匹配 → 生成或读取已有分析 → 同屏查看原页与建议 → 教师记录评分及诊断 → 按已有标签寻找复练题。

**连续批改多人：** 学生分析 → 作业批次 → 新建批次并明确选择每名学生的一份已有作答 → 逐人/逐题核对 → 正式记录分数，未完成输入可暂存 → 标明待核对或缺页等情况 → 下次重新打开继续。可用“正式评分统计”查看同一原题组的已确认结果；不自动完成所有学生的模型分析，也不混排不同试卷。

**从一次考试安排复练：** Excel考试分析或作业批次正式评分统计 → 选失分题及学生、填写可检查目标 → 去真实题库按标签选题 → 返回任务勾选专用题目 → 预览并导出两版练习卷 → 学生实际作答后记录日期、分数/缺失情况 → 导出含复测记录的报告。

## 4. 首页：从已有工作继续

![首页：最近作品、当前编辑和实际题篮；0.1.94历史实际截图](docs/screenshots/v0.1.94/typography-home.png)

最近五份当前作品按保存或更新时间展示，选择后打开；更早作品在“全部备课”中搜索。归档、回收站不混在当前作品里，保存时间不冒充最近打开时间。

“继续编辑”回到原备课表单，不清空材料、不发起模型调用；“新建备课”有未保存内容时会确认。右侧使用真实题篮，查看、调序、继续选题及预览试卷共用同一批已选题。底部题库/教材状态按展开读取，不用宣传卡片占满日常工作区。

## 5. 选题中心：左侧标签，右侧原题

![选题中心与完整题面；0.1.95实际合成验收截图](docs/screenshots/v0.1.95/explorer-loaded.png)

先在左侧选择实际拥有的资料来源，再使用来源支持的教材、章节、知识点、年级或考试类型筛选。**同类满足任一条件，不同类同时满足**；删除顶部标签可单独取消一个筛选。来源选择会记住，空结果可切换已导入Word或图片题，不把空原卷目录误当所有库都没有题。

右侧题卡可展开题面、公共材料与图片，并切换答案/解析。核对后加入题篮，已加入状态不会因翻页丢失。题篮中的一项可能是带多个小问的完整主题，不等于一条最小作答单元。依赖共同材料或前题条件的小问不作为缺条件孤题导出。

个人目录首次读取后建立可丢弃索引；同来源最多缓存四组匹配结果，后续筛选/翻页复用。Word同标签页多图合并读取，答案按需展开；不通过降低原图质量换速度。导入、标签管理和“重新读取”会更新快照；外部直接修改来源文件后需手动重新读取。

左侧“复制加载记录”只复制各阶段耗时和数量，不含关键词、题面、路径或密钥。首次大目录、旧公式转换、大图解码和外部磁盘仍可能慢，局部性能数字不是全库冷启动承诺。

## 6. 题篮、组卷与连续题号

![原生组卷页面；0.1.94历史实际窗口](docs/screenshots/v0.1.94/packaged-paper.png)

题篮可查看、上移、下移和移除，移除不删除原题。**“预览试卷排版”使用当前题篮；“进入组卷编辑”继续组卷草稿**，两者不要混为同一范围。混合组卷编排Word原题与图片主题，保留完整共同材料、已有公式和作答区域。

教师可调整卷名、用时、题序、配分与当前编辑页支持的作答设置。未知分值需要核对，不能作为确定的0分。原题已有横线、表格或绘图区时不重复添加。生成后切换学生版/教师版逐页检查，确认后导出本次核对的同一批文件；调整题序后重新生成预览。

### 文字题号与图片题号

可编辑文字题号按本卷顺序重新编号，对应答案同步；同来源且对应唯一的文字引用跟随更新。题内(1)(2)层级、选项、公式上下标及12.5等数值不做粗暴数字替换。教师来源说明保留原题号，便于回查。

![图内编号区域复用；0.1.94实际合成验收截图](docs/screenshots/v0.1.94/scan-reused-regions.png)

扫描图片内部的旧号在混合组卷 **“调整图片题号后预览…”** 中处理。选图，只框旧号，填写本卷号码并添加替换；可原图对照、撤销、移除或清除。修改写入学生/教师DOCX副本，再进入实际PDF转换，不只是窗口遮盖。原图不改写，框外像素保留。

“记住此图位置”只存原图身份、尺寸和坐标，不保存旧卷新号码；下次“载入位置”后核对当前号再应用。能唯一对应一条Word印刷题时提供本卷号码建议，共享材料或多义对应不猜。图内“见第N题”等引用须另核对目标。

当前限静态PNG/JPEG/BMP白底数字方式；彩底、旋转、同图不同实例需要不同编号和复杂跨页来源仍有待补齐。答案标题/短首段与首内容块关联分页，长答案不强制挤在一页。编号正确不代表所有复杂卷面已终验。

## 7. 学生分析、同屏批改与作业批次

### 上传、匹配和分析

学生以已有匿名代号管理。按当前界面选择原题、学生作答、参考答案页，先在本机准备并核对页码对应和满分，再确认需要发送的材料及模型。资料不足、匹配不明或模型不支持图片时，不应把文本联通当作识图通过。

已有分析可重新打开，不需要重新收费调用。原作答、模型建议和教师决定分别保存；“不能据此判错”的信息不是已确认的0分。真正模型识别准确率取决于所选模型、页面质量和人工核对，本版合成测试不构成准确率证据。

### 一份作答的同屏复核

![原作答与教师评分；0.1.96实际合成验收截图](docs/screenshots/v0.1.96/student-review-wide.png)

打开已有分析后，点击顶部 **“打开作答与评分（同屏批改）”**。左侧选题，中间切换学生作答、原题/公共材料和参考答案，右侧分为“教师评分”与“AI建议”。支持适合宽度、整页、缩放和拖动；AI证据框需对应实际页面，框线不修改原图。

新分数留空，明确填写分数和理由后点击“记录本题评分”。诊断单独记录，可采纳、修改、不采纳或暂不判断；修改分数后旧诊断需重核。目前修改的是题目总分与诊断，并非每一个AI评分点都已有独立改判编辑器。

单份旧窗口在当前窗口内保留切题输入；持久暂存用于下方**作业批次窗口**。两者界面明确区分，不把未记录的输入说成已保存评分。

### 新建批次并选择已有作答

![学生分析中的作业批次入口；0.1.97实际窗口](docs/screenshots/v0.1.97/work-batch-entry.png)

点击 **“作业批次→新建批次”**，填写作业名称，班级备注可不填。勾选实际属于同一作业的已有学生作答，每人只选一份；同一个学生有新旧版本时由教师明确选择，不根据文件名推断姓名、班级或试卷。

![选择学生与已有作答；0.1.97合成验收](docs/screenshots/v0.1.97/work-batch-members.png)

选择器读取全历史而非只截最近50份。搜索只隐藏不匹配项，不清空已勾选内容。保存后可通过“编辑批次”重命名或调整成员；改变成员不删除原作答、正式评分或暂存。批次是引用分组，不再复制整套学生库。

### 在同一窗口逐人复核

![批次内原作答、评分与情况记录；0.1.97合成验收](docs/screenshots/v0.1.97/work-batch-wide.png)

顶部选择批次与学生，或用“上一名／下一名”。一名学生内部仍用原来的上一题/下一题和原页阅读器。切换时先处理当前暂存，再读取新学生，加载失败不会沿用前一名的图。

某份作答没有已有分析时，会说明需回学生分析完成原流程；批次窗口不会自动发起模型请求。此版是**已有作答的批次复核**，不是批量上传、一键循环调用模型或班级自动打分平台。

### 暂存输入与正式评分分开

![返回该生后恢复暂存输入；0.1.97合成验收](docs/screenshots/v0.1.97/work-batch-restored.png)

在批次窗口，切换学生或返回时会暂存尚未记录的分数、理由、诊断输入和作答情况输入，也可以主动点击 **“暂存输入”**。重新打开批次后可继续；暂存不改模型稿、不算正式得分、不更新错因统计。

点击“记录本题评分”才写入原评分服务；成功后清理该题已经记录的对应暂存字段，其他题未完成内容保留。“清除暂存”需要确认，只清未记录输入，原评分、诊断、原图和批次不删除。

暂存写入失败时留在当前学生，不悄悄切走。已有正式记录或原题对应发生变化时提示核对，原题变化的旧暂存不会直接套用。此版没有每键自动保存：**异常退出前未点暂存、未切换/返回的最新输入仍可能丢失**。学生目录仍未纳入备课备份ZIP。

### 记录未做、缺页等实际情况

可选择 **未标记、待核对、资料缺页、未作答、尚未学到、作答时间不足、图像难辨**，填写观察依据后点击“记录状态”。除了清回未标记，需写明依据；程序不会把空白自行判断为不会。

![教师记录情况，不自动改分；0.1.97合成验收](docs/screenshots/v0.1.97/work-batch-condition.png)

情况与评分是两个维度：标记资料缺页不自动改成0分，取消状态也不会删除正式分数。状态保留修改记录，尚未记录的选择只作为输入暂存。可进一步打开“正式评分统计”：只合并原题页、题号、满分及答案来源一致的评分组。未评分/未核对/缺页等记录排除，暂存和AI建议不计入。**不按不同试卷或未批完分数混算班级均分、排名和能力雷达**。

![800×700紧凑布局；0.1.97合成验收](docs/screenshots/v0.1.97/work-batch-compact.png)

### 复练边界

## 考试数据分析：成绩Excel＋试卷＋API讲评

**入口：学生分析 → 考试分析（Excel）**，或按`Ctrl+K`搜索“考试分析”。这是已有原生工作台内的考试面板，不需要搭建Web服务器。图表用本地确定性统计，API仅生成讲评和行动建议，不执行模型返回的HTML或代码。

### 1）导入、映射和检查

![成绩列、题号与真实满分映射；0.1.98合成验收](docs/screenshots/v0.1.98/exam-import.png)

点击“保存Excel示例”可取得含**成绩／题目映射／使用说明**三张表的xlsx。示例全为合成数据，请替换为自己的一场考试：一行一名学生、唯一学号或标识、一列总分及可选逐题得分；不要夹带合计/均分行或多场考试。也可直接使用自己的普通xlsx，不强制套模板。

选择工作表与真实表头行，映射学生、班级、总分及可选缺考状态列；明确试卷满分、达标线和高分线。默认100/60/85只是可修改的分析参数，不是上海等级考官方赋分标准。学号数字的显示格式不等于原始值，前导零请在Excel以文本保存。

有小题分数时，在第二页勾选对应成绩列，填写本卷题号、**真实满分**、单一主知识点、章节和公共材料说明。可读取“题目映射”工作表，但需要教师核对。不能从最高实得分猜满分，也不能同时勾大题总分和所属小问；按题目加总时必须映射全部非重叠评分单元且满分之和吻合。不自动生成未经核对的知识点映射。

**只有总分仍能用**，但不生成逐题/知识点掌握结论。空白、未批和缺考不当0分；负分、超满分、Excel错误、未缓存公式等进入“数据核对”。完整小题合计与总分冲突时排除该行总分，保留有效小题并指出冲突。重复学生标识会要求先修正，不静默合并。

公式只读Excel已经保存的计算结果，不运行宏或重算公式；缓存可能过期，导入前请在Excel重算并保存。隐藏行/筛选行也会读取。仅支持普通`.xlsx`，不支持旧`.xls`、加密文件和宏表。每表最多10000行、256列、最多映射200个评分单元；超范围请按同场考试/班级拆分。

### 2）本地可视化面板

![总览：分布、均分、有效人数与班级表；0.1.98](docs/screenshots/v0.1.98/exam-overview.png)

总览显示导入人数、有效总分人数、均分、中位数、总体标准差、自定达标/高分人数及比例、缺考和总分缺失；分布以满分百分比分段，左闭右开，最后一段包括满分。比例明确分母，只对有有效总分且非缺考者统计。顶部可以切换班级或全部导入班级；同一张表须属于同一考试，不能无说明混算不同试卷。

![逐题与知识点图表；0.1.98](docs/screenshots/v0.1.98/exam-items.png)

逐题显示有效人数、缺失人数、满分、均分与得分率。图中优先列出最多20项低得分率题，完整明细保留在表格；知识点按有效作答对应分值加权，不把多题均分简单平均，也不称为精确能力指数。未提供映射的内容保留“待映射”，不伪造掌握结论。

![学生得分热力表与复核行动；0.1.98](docs/screenshots/v0.1.98/exam-students.png)

学生页用原始分数、临时代号与热力底色展示得分。点击学生可查看具体失分题、还缺哪些成绩、下一步应核对什么及短测安排。底色只是阅读辅助；缺考/缺失为“—”，明确0分保留0。仅凭分数不能判定粗心、态度差或确定错因，本地行动是复核优先级，不是标签化的学生能力结论。这里的S代号只在本次考试导入内有效，不会按姓名自动合并到原学生作答档案。

### 3）添加试卷，再让API生成讲评草稿

![试卷正文、API选择与讲评草稿；0.1.98](docs/screenshots/v0.1.98/exam-api.png)

“添加/替换试卷”支持DOCX、PDF、PNG/JPEG/BMP。Word复用原生正文与公式/表格读取，不把Word整页裁图；PDF同时保留文字层及整页查看副本。图片中的公式/有机图不能仅靠文本转写推断。单次至多12页PDF或12幅图；超过范围会提示，不自动丢掉试卷后半段。公共材料随原文保留，教师可在文字区校对，亦可追加教学进度与已练内容。

从已保存API配置中选模型。**仅文字API可以分析成绩及已核对的文字材料**；需要解释扫描/图形条件时，先查看试卷图，再勾选“发送已选试卷图”，模型必须已配置视觉能力和图片发送许可，否则调用前明确提醒。声明支持看图不代表识图质量已经验证。

默认只发送匿名汇总、题目映射、试卷文字及教师说明；姓名、班级名称、学号列和Excel文件不进入模型请求。可明确勾选“附匿名逐人成绩”（每次最多100名），只使用S代号。自由文字、题目备注和图中个人信息**不自动脱敏**，发送前对话框显示接收模型、完整文字资料、学生数量及图片清单，确认才调用，可能计费。不会读取对话历史中曾粘贴的密钥来测试。

API返回班级讲评重点、分层行动、下一课安排、复测计划与局限；建议引用已有题号，未知题号/学生代号拒绝纳入。API不能改写图表数字；建议格式异常、超时或取消时本地图表仍可用，不自动反复收费重试。模型草稿需要教师核对，尤其是没有原作答时只能提出待验证假设，不承诺提分。

### 4）保存、导出和带入备课

导入后保存本机快照；试卷文字或说明修改后点“保存分析”。“打开历史分析”可恢复已保存数据与对应范围的建议，无需重新读原Excel或调用模型。切换班级不会把另一范围的AI建议直接重标成当前班级结论。编辑材料会使旧建议失效；关闭前提示保存。数据存放在个人状态的`exam-analyses`目录，含本机学生标识，文件不加密。

“导出可视化报告”生成带SVG图表、指标、题目/学生明细和建议的离线HTML，无远程脚本。导出时可选择保留本机学生标识或临时代号，自由文字仍请自行检查；它不是Excel文件备份。“带入备课材料”追加当前统计摘要和讲评草稿，不覆盖原材料、不自动调用模型或制作PPT，返回备课页核对并保存。

![800×700考试面板；0.1.98](docs/screenshots/v0.1.98/exam-compact.png)

考试分析记录目前**不包含在备课备份ZIP**，也没有实现跨考试可比趋势或自动补测回写。下方复练任务可以关联真实题库项目并手工记录复测，但不是自动推荐排序，更不会自动形成已提高的结论。单次考试可以制定提升计划，不能证明提升已发生。需用后续同目标测验和可比较数据验证效果。

## 评分—复练—复测：让分析有后续动作

### 1）从已有作答读取正式评分，不再手抄一份Excel

**学生分析 → 作业批次 → 打开批次 → 正式评分统计 → 选择同卷组。** 当前在编辑的内容先按原规则暂存；统计只读取已点击“记录本题评分”的教师决定，不把暂存或模型建议当得分。

![同卷组正式评分进入考试面板；0.1.99合成验收](docs/screenshots/v0.1.99/closure-batch-stats.png)

只有原题页内容、题号、满分和答案来源一致的作答单元才合并；不同试卷拆成不同组。未评分、待核对、缺页、未作答、尚未学到、图像难辨不按0分填补。已记录“时间不足”且仍有有效正式分数的作答保留分数，教师可继续核对。

这是**所匹配评分单元的只读快照**，不保证覆盖完整原试卷。快照保留批次、原作答及评分版本；正式改分后再次从批次生成统计，旧快照不会自动悄悄变化。60%/85%仅默认分析参考线，不是上海官方等级划分。知识点留待核对，不从分数反推知识掌握。

### 2）明确复练对象和目标

在考试分析的 **“复练与复测”** 标签中，选择有逐题映射的考试题目，点击“建立复练任务”，勾选该题有有效成绩的学生，填写一个可检查的学习目标和计划日期。只有总分或该题缺失的学生需要先补充证据，不能凭空建立“已经失分”的结论。

![目标、所选学生与实际复测进度；0.1.99合成验收](docs/screenshots/v0.1.99/closure-panel.png)

任务随本场考试保存，可以从“打开历史分析”继续。考试内的S编号仍不能自动等同另一场Excel的S编号；本版不按名字猜合并学生档案。

### 3）使用原有选题中心，不生成假的推荐题列表

点击 **“去题库按标签选题”**，选本地Word或个人图片来源，再从该来源实际存在的有效知识标签中确认对应。考试标签与题库标签不会不经核对直接视为相同；没有有效标签或没有匹配结果会明确提示。

![保留完整原题、来源与原题篮的选题衔接；0.1.99](docs/screenshots/v0.1.99/closure-library.png)

回到原有左标签/右题面的选题中心，保留原题阅读器、答案与公共材料。查看后入篮，再点击上方 **“返回复练任务”**；不需要复制题文或另建题库。普通安装缺少私有教材目录时，仍可使用已有K01—K19基本知识分类，但不会编造教材章节。教师本地已安装目录损坏时仍提示修复，不静默覆盖。

### 4）只编排本任务选中的题目

返回后点击 **“关联题篮中的题”**，只勾本任务要用的项目。全局题篮里为其他班级或课程准备的题不会自动混进来；新卷只使用这些明确关联项的顺序。原题篮及旧组卷草稿保留。

**“预览本任务练习卷” → 查看学生/教师两版真实PDF → 确认 → “导出已核对练习卷”。** 导出使用原有组卷链，记录本次题目引用和文件位置，不只是产生一份练习方向文字。题目移出题篮或修订发生变化后，重新关联、核对再预览，不悄悄换题。

![本任务学生/教师两版实际排版核对；0.1.99合成验收](docs/screenshots/v0.1.99/closure-preview.png)

当前任务预览不额外提供图内题号调整窗口：图内旧号仍需核对，复杂扫描题可回原混合组卷流程处理。没有将所有历史图号功能冒称已自动接入这个新入口。

### 5）学生做过之后，再记实际复测

点击 **“记录实际复测”**，选择任务中的学生，填写真实日期、已作答/未作答/资料不全；已作答时明确实得分、实际满分和观察依据。实际日期不可填未来；未作答和资料不全不记为0分。

![800×700保留任务记录阅读区；0.1.99实际窗口](docs/screenshots/v0.1.99/closure-retest.png)

记录以追加方式保存并保留当时的题目引用；当前概况使用每生最新录入的记录，旧记录仍在保存文件中。原考试和复练题不一定等值，**不直接相减宣称提升了几分**；任务完成也不代表知识已经永久掌握。导出可视化报告时会追加当前班级范围内的复测记录，姓名开关不自动清除教师自由文字中的个人信息。

### 6）哪些仍未完成

本轮补的是人工可核对的关联和实际结果，不是全功能已闭环：自动诊断选题排序、跨考学生身份、跨卷量尺对齐、自动批量分析、原作答附件式复测、全业务备份仍待实现。备课建议单向带入已可用，教案/PPT/学习单的教学节点同步更新仍未完成。逐项见[联动审查与补充验收项](docs/ux/0.1.99-closure-audit.md)。

## 8. 备课、教案与PPT

![备课固定操作区；0.1.94历史实际窗口](docs/screenshots/v0.1.94/scale-1-typography-compact.png)

填写课题、授课对象、课型、课时、教学目标与实际材料，再选择当前任务支持的输出类型。顶部可定位教学要求、备课资料、进度与结果；底部保存/生成保持可达，不必滚到表单最末寻找按钮。

资料可从Word内容、教材知识点、完整题目、命题方案和已核对材料带入；追加参考不应覆盖原课题与已填目标。Word文字直接读取，图片保留原页或独立引用；是否让模型读图由配置、能力与发送确认决定。

生成前核对模型、资料、页数和预算。查看返回稿，核对目标、讲解、问题情境、学生任务、例题、独立练习、反馈与课堂收束是否合理，再修订导出。软件应组织一节课而非只是罗列题目，但生成质量仍需人工把关。

PPT输出使用可编辑PPTX；现有快速预览由共享布局绘制，**不是PowerPoint对实际PPTX的最终渲染核验**。字体替换、复杂化学图形与投影效果应打开最终文件核对。当前修订和序列操作沿用已有能力，完整目标—活动—评价三栏节点编辑及全部输出联动仍在路线图，不以固定导航冒称已完成。

备课恢复副本约每两秒检查编辑，正常关闭再保存最后修改；正式“保存草稿”用于保留版本。恢复副本不是原图备份，已被外部删除的图片不会因恢复表单自动找回。模型失败后已保存内容仍可查看，不应无解释地重复整次收费生成。

## 11. 我的备课、作品整理与备份

![作品查找与整理；0.1.94历史实际窗口](docs/screenshots/v0.1.94/typography-mywork.png)

## 12. 导入资料、教材映射与标签

![通用文件导入在前、旧资料包在后；0.1.95实际窗口](docs/screenshots/v0.1.95/import-files-first.png)

从右上角“导入资料”选择Word、PDF或图片，按试题、参考答案、教师讲义等用途放置文件。可预览并选择导入范围；保存过的批次即使后来取消窗口也可能已存在，退出后选题快照会失效刷新。

Word可读正文直接提取，保留公式及嵌入图，不把全部Word转为大截图。不能读取的旧公式对象或扫描页按原流程提示，可回原文件核对；视觉识别需合适模型与明确发送确认。自动切割不能免除题答分离、跨页公共材料、边缘裁切和已有答题区域的复核。

来源管理可按实际支持范围维护知识点、教材册/章/节、年级和考试类型。只保存有依据的标签，不按学校名、题号、难度印象或文件名猜填“官方”“一模”等字段。筛选与推荐是否命中取决于有效标签；已填字段数不等同于整库完成核验。

旧98份资料包入口仅供本机实际拥有该资料包的环境，普通文件无需使用它。软件没有附带这份资料包，也没有因更新自动完成用户本地公众号、Word或教材的重新导入与蒸馏。

## 13. 模型设置、字体与本机检查

![基础连接设置；0.1.94历史实际窗口](docs/screenshots/v0.1.94/settings-basic.png)

填写服务商、Base URL、实际模型名、API密钥与接口格式后保存。高级预算默认收起，已有参数仍保留，留空使用原默认策略；预算不是厂商容量或计费保证。

保存配置只改本机记录；测试连接会另行确认并发送固定短文本。修改配置后旧成功记录不代表新配置已验证。**允许发送图片、模型宣称支持图片、实际读图质量通过是三件不同的事**。文本API不可因能聊天而被当作已具备视觉解析、化学图识别或结构化输出能力。

![中文和化学符号检查；0.1.94历史实际窗口](docs/screenshots/v0.1.94/scale-1-typography-sample.png)

状态栏“本机检查”显示版本、源码/打包身份、组件、资源、目录可写性、Office安装发现和实际中文/化学符号字形。检查不读密钥、不扫描全题面、不自动请求模型。发现Office不等于真实转换已通过。

界面优先使用本机实际可用中文字体，正文11磅、部分辅助字9.5磅，并保留化学上下标和箭头的字符回退。`Microsoft YaHei UI`是微软雅黑的英文名称，不代表用英文字体画汉字。界面修复不修改原图片、Word、PPT或PDF字体。

## 14. 常见问题与快捷入口

| 现象 | 处理方法 |
| --- | --- |
| 更新后还是旧版 | 确认运行新解压目录的EXE或源码启动脚本，查看状态栏版本，不沿用可能指向旧版的VBS |
| 明明导入过，选题却为空 | 切换到对应的本地Word/个人图片来源，清掉过窄标签并重新读取；查看导入实际保存结果 |
| 点击题目仍慢 | 用“复制加载记录”区分目录/索引、题图和卡片阶段；大文件首读与复杂公式仍有成本 |
| 新卷出现旧题号 | 可编辑文字重新生成预览；扫描图使用图内换号入口，图内引用另核对，旧成品不会自动改写 |
| 新批次里无法复核某生 | 批次只分组已有作答；该生尚未完成分析时需回学生分析完成原流程，不会自动调用模型 |
| 切换后分数栏恢复了但统计未变 | 恢复的是暂存输入，正式分数须点击“记录本题评分”；未评分不是0分 |
| 缺页状态和已记录分数同时存在 | 状态与评分独立，教师需核对是否修订分数；软件不会自动删分或判零 |
| 暂存失败无法切换 | 当前输入仍在，先检查本地可写性；记录冲突需重新读取后核对，不会写到其他学生 |
| 恢复备课后没有题库或学生作答 | 备课ZIP并非全工作台迁移，原题库与学生业务当前不包含 |
| 成绩图表没有小题或知识点 | 只有总分或没有明确映射时不虚构分析；在导入页勾选非重叠小题列并填真实满分/知识点 |
| 公式分数未读到 | 先在Excel重算并保存；无缓存不记0分，当前软件不执行Excel公式 |
| 文本API无法分析扫描试卷 | 用支持视觉的模型并明确允许图片发送，或粘贴已核对的题目文字；总分统计不需视觉API |
| 从题库回来后找不到复练题 | 在任务中点“关联题篮中的题”明确勾选，题篮备选项不会全部自动带入 |
| 复测记录已有分数但没显示提分 | 原题和复练题未必等值，程序仅保存实际日期与分数，不把两次不同题的差值当学习增益 |
| PPT预览好看但Office打开不同 | 快速预览不是实际Office渲染；检查字体、换行、上下标与最终投影效果 |

`Ctrl+K`搜索功能，`F1`打开帮助，`Ctrl+1`至`Ctrl+5`切换原五个主页面。窗口常用操作使用完整中文用途，不需要输入后台ID。

## 开发定位

原生界面在`integrations/deeptutor_shchem_v1/desktop_workbench/`；题目、组卷、备课与学生服务在同级模块。批次仅引用既有学生/作答身份；`desktop_work_batches.py`保存分组、状态与暂存，`work_batch_desk.py`嵌入既有复核器；`desktop_batch_exam.py`读取正式评分，`desktop_exam_followup.py`保存考试内复练/实际复测，`exam_followup_panel.py`连接原选题和导出。运行与打包入口位于`runtime/deeptutor_shchem/`，定向测试在`staging/coordination/deeptutor_gateway/tests/`。

同类项目/作者公开工作流的取舍见[工作流与开源借鉴研究](docs/research/0.1.95-workflows-and-references.md)。本版不新增Coze/Dify服务器、不用Web替代原生桌面，不把作者收费插件当作本项目已实现能力。
