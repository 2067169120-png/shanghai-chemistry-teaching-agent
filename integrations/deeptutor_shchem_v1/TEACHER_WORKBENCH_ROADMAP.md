# 教师工作台闭环实施与验收清单

更新：2026-09-10。依据教师本次需求；按阶段实施，不表示下列功能均已完成。

主线：导入资料 → 提取正文与图表 → 题目结构和教材知识 → 教师确认 → 选题、备课或材料命题 → 题目与答案核对 → 预览导出 → 保存修订历史。不同功能共用资料和来源，不维护互相脱节的副本。

## 当前 0.1.52 的实际范围

- 新文件可以导入前逐份查看原文/支持的图片/PDF页，勾选整份来源后确认保存；确认时重新核对文件内容与角色，取消不保存。尚未将所有软件功能都宣称达到相同预览标准。
- 46份讲义建立262条知识、48条方法及56条易错/待核索引；383条既有教材概念整理为可版本管理的派生包。摘要不替换现成教案，原文件和完整例题仍为首选阅读内容；没有声称本轮重新逐页审定全部教材。
- 大同高一期中 41 道印刷题、56 个作答单元的 AI 补充答案；原来源“未附答案”的状态不变。
- 26 个展示裁图修订，保留第 33 题 A—E 公共条件；来源原件和原裁片不覆盖。
- 已核对的本卷作答单元默认利用原题空格、选项与绘图区，不自动追加横线；教师逐题指定过程区仍有效。尚未推广为所有新上传题目的自动区域识别。
- 题面默认不添加分数，教师可选择显示；教师版评分答案始终保留每题总分及各小问分值。原图中已有分数不涂改；显示选择进入已确认预览与导出设置。
- 氯、氧原子图参照用户提供的沪科技版必修第一册第 129 页，改为核电荷圆圈、右侧分层弧线和电子数；另有氯离子电子式和单线桥电子转移图，均提供可编辑 SVG。
- 备课、命题蓝图及蓝图审校共用 `teacher-source-closure-v1` 规则，约束教材对应、材料完整性、Word 正文使用、已有答题区、图形需求和能力边界。规则接入不等于自动导入、选题或绘图引擎已实现。
- 图片导入已有视觉能力与出站权限前置检查；文本连通性成功不会自动证明具备视觉能力。更正上一版范围说明：此前桌面已支持纯文字 Word 导入，并非所有 DOCX 都先转页图。
- 本版统一原生段落中的上下标、可解析 OMML、特殊字符及可见性；保留表格合并和包装内容控件。已保存 Word 可重开查看正文和可支持的内嵌原图，按选定区块预览后追加备课。来源哈希与内容版本在确认时复核，老师原设置不被覆盖。
- 含旧公式或图片的 Word 仍标记为需视觉补全，但已经读出的文字可先使用，缺口留在原位置。可解析 OMML 的文本表达不等于完整 Word 排版重建；图片预览不等于装置/有机结构已经识别。
- 已归档Word的逐题索引与窗口识别题面、答案和共同材料，支持来源筛选、关键词、逐题勾选、范围修订、重开恢复，以及具体选题追加备课。98份现为3572条候选、25个完整主题；旧105条未定位答案已分类修复，所有候选找到原答或解析区块但不代表各小问答全。4条仍有题答边界问题，已知源缺答另列AI补充。292条新增均核对文本起止与题答衔接，原Word和预览区块不改。
- 3572条保存可追溯自动属性建议，2358条有主知识点建议、755条有教材节候选；界面可查看依据并修订标签，预览变更后才写入，取消不保存。适用年级与原题年级分开，知识点/年级/考试类型可组合筛选且保留题篮。旧教师标签不会被重新分题的自动批次覆盖，显式重标后保留旧历史。尚未接通统一原卷题篮和依赖智能选题，不把自动建议计作教师确认。
- 新Word选题可独立导出学生练习与教师答案，保留支持的原生表格、公式和内嵌原图；本次配分可修改，学生显示可选，教师答案始终显示。尚未合并到原卷主题题篮。
- Word选题默认图文一起带入备课，原图按内容去重，并保留题面、共同材料和答案的对应关系；现有表单不覆盖，超出12张或存在不支持图时整批不追加，可明确选择仅文字。当前备课模型只接收图片说明，像素留本地供排版，尚未打通多模态备课。

0.1.52已接入EMF与EMF+本地转换预览，71种原图（89处引用）完成实际渲染检查。EMF+不能仅用传统GDI，否则可能剩下上标而主体丢失；现用系统GDI+内存路径。WMF不再以先前两个非空样本当作可用依据：批量对照发现字体缺失与挤字，8586处引用仍保留原Word核对。跨进程少数EMF+边缘像素可能略异，保留原图SHA、派生SHA和重新预览检查。下一批优先解决WMF保真、更多原题小问答案完整性，以及统一题篮/智能选题和多模态备课，不以本轮软件通过替代课堂核验。

## 第一阶段：正文优先导入与可复核切题

1. 输入分流：DOCX 解析原生段落、表格、上下标、OMML 公式与嵌入原图，保留文档顺序和来源锚点；有文本层 PDF 优先利用文本与图形；扫描件才进入页面视觉切题。旧 DOC 文件先经过可核验转换，不把扩展名当作正文证据。
2. 公式或图片无法转写时明确标记局部缺口，不能静默删掉、把公式拆成乱码，或为方便而把整份 Word 都裁成图。
3. 保存 paper → theme_big_question → printed_question → atomic_part 四层结构；公共材料、跨页延续和前序结论依赖明确关联。切题结果并排显示原页和候选，允许教师调边界、合并和拆分。
4. 裁图检查：题号、题干、选项和必要装置完整，不能混入相邻题残片；原本答题区域单独标识并保留；来源标识不涂改。机器边界检查与实际图片复核分别记录。
5. 在发送前按任务检查 text、vision、结构化输出等能力和用户允许的材料范围。纯文本模型可继续处理真实提取的文字；扫描件无法识别时提醒换配置或补文本，不把“不能看图”笼统变成所有资料均不可处理。

验收样例：纯文本 Word 无需视觉调用即可提取；带公式、表格和图片的 Word 不丢关键内容；跨页试卷题干完整；纯文本模型收到扫描件时显示明确中文提醒且不发起无效调用；修改切题边界后可回溯原件。

## 第二阶段：已有题库标签与教材、讲义蒸馏

每个作答单元分别维护主知识点、辅助知识点、教材版本/册次/章节、适用年级及依据、原试卷年级、考试类型、年份、区域/学校、作答形态、来源定位、答案状态、共享材料和依赖。以主库知识目录做规范化映射，保留 AI 建议、教师修改及版本；未知信息不从文件名、题号或题目难度猜测。

知识点蒸馏保留：概念原句及定位、适用条件、概念联系、完整知识表、例题、解题方法、易错点和对应练习。原句、归纳、AI 解释分开。常考总结有可记录的具体结论，不伪造考试频次。目录只代表结构，不能代替已读取的教材或讲义正文。

验收样例：同一个知识点能定位到教材原句、讲义例题与题库题目；教师改标签后，备课检索与组卷筛选结果同步变化；考试类型与选择/填空等作答形态不会混为一类；标签建议可解释、可撤回。

## 第三阶段：智能选题与两课时讲练

教案、PPT 与组卷共用检索服务。教师可限定知识点、章节、年级、考试类型、难度意图与数量；AI 返回选题理由、来源、材料成本与缺口。范围不足时说明，不悄悄换成外省卷或原创题。

选择小问时计算材料和前序依赖的传递闭包：必要公共材料全部保留、重复图表去重，仍依赖未提供内容则带入完整印刷题或阻止不完整选择。默认不把主题抽散为独立选择题板块。

PPT 从章节首页开始，按“情境/问题—教材概念及条件—讲义例题示范—独立练习—答案讲评—常考知识表与笔记—回扣检测”组织；每个课时有明确起止、活动和记写时间。题页不提前展示答案，教案、PPT 与学习单使用同一题号和条件；教师可调整而不是锁死模板。

验收样例：筛选一个依赖公共实验装置的填空时装置自动随题；跨小问结论不会丢失；两课时讲练分别有知识、例题、练习和笔记产出，不是知识点列表换皮。

## 第四阶段：基于材料命题与可编辑化学图

教师确定材料、范围与改编授权 → 生成主题蓝图 → 补齐共同材料、题干、答案和解析 → 输出结构化图形需求 → 确定性绘图 → 化学与版面检查 → 教师确认。已有蓝图功能保留，不把蓝图直接标作完整试题。

装置图需校验仪器连接、气流方向、液面、密闭性与试剂条件；有机图需校验原子价态、键、结构连接、电荷与所考异构关系。结构正确性、来源支持、图片美观分别验收。可编辑 SVG/结构数据为正式图形载体，生成式图片只适用于合适的视觉素材，不能替代化学结构校验。

验收样例：改了试剂或有机结构后，图、题干、答案同步更新；修改条件会触发相关答案重新检查；缺失图不能导出成“见图”但实际无图的题目；学生版不含答案、答案替代文字或隐藏备注。

## 第五阶段：学生学习跟踪与题库推荐

学生作答记录关联到具体题目与作答单元，分别记录知识点标签、错误类型、作答时间、教师批注与后续复练结果。后台提示词须区分“本次答错”“重复错误”和“证据不足”，不能凭一次作答断言掌握程度，也不能把未作答当作不会。

推荐步骤为：读取教师授权的学生记录 → 汇总可解释的薄弱知识点 → 在题库范围内检索基础巩固、同类变式和迁移题 → 补齐公共材料与前序依赖 → 返回具体题号、来源、推荐理由和建议顺序 → 教师确认 → 收集再次作答。没有合适题目时明确说明题库缺口，不虚构推荐题目；标签更新和题目修订应同步影响后续推荐。

验收样例：每道推荐题都能在软件预览并选入练习；老师能看到推荐所依据的具体错题；复练后更新学习记录，不以“推荐过”代替“已经掌握”。学生资料与模型出站范围由教师确认，公开截图仅使用演示数据。本阶段是待实现要求，不表示自动跟踪及推荐链路已经完成。

2026-09-10代码核对：后端 `StudentRecommendationWorkbench.preview` 已返回实际题库的完整主题、命中作答单元及可加入题篮的选择，不是只有泛泛建议；原生学生页尚未调用。下一步接通“教师确认诊断 → 具体题目推荐 → 查看整题/加入题篮”。跨作业时间线与复练结果尚未连通；上传题来源未知时不能承诺排除原卷所有重复题。

## 本地资料全量导入与标签补齐

当前教师明确指定的题库范围：①《【上好课】2026年高考化学一轮复习讲练测（上海专用）98份》压缩包中的98份解析版，题面、答案和解析关联提取，不重复导入学生版；②此前已收集的公众号图片题。暑假同步讲义仍可用于备课资料参考，但不计入这次指定的题库导入范围。

讲义本身是现成教案，直接保存和提取完整文字、表格与图片，不先重写成摘要再导入。其知识点讲解另外建立概念与条件、知识联系、归纳表、典型例题、方法与易错点的检索索引，关联到后续教案及PPT。原句、蒸馏归纳、AI补充分开标注，保留来源位置及对应题号；不以章节目录或摘要代替原教案。

按“源文件清单 → SHA去重 → 已归档比对 → 原生正文提取 → 逐题候选 → 标签建议/教师修订 → 检索使用”推进，分别报告文件数、题数与已确认标签数。不得把磁盘已有、旧教学包已有、测试状态已导入混称为用户工作台已经全部可用。

化学资料和混在同一文件夹的其他学科资料分开；临时锁文件不导入。Word教师版/学生版或试卷/解析版按真实内容配对，不因文件名相似就合并；公众号资料保留原卷与共同材料，不重写原来源。题目年级、考试类型、教材章节点、主辅知识点分别记录，现有章节标题不直接冒充标准标签。共享材料依赖、原图缺口和答案状态在导入及后续选题中继续可见。

公众号题缺答案时按上海高中化学范围补充解答、评分建议和必要图示，标为AI补充解答并保留来源原答案状态；已有答案优先关联原答案。答题所需原图或条件缺失时先补齐题面，不以臆造条件完成答案。

## 版本与产品体验

提示词、输入输出契约、能力检查和测试一起版本管理。每阶段保留代表性资料回归集，但不上传原教材、完整教案、学生资料、个人配置或密钥。提交包含允许的软件源代码、测试、说明以及用户授权的简明改述知识索引；不包含原资料再分发。

每次发布更新README中的实际功能、操作入口与步骤，以及对应版本的页面截图。截图使用可公开的演示资料，不上传用户讲义、教材、真实学生记录和个人设置；功能截图不能冒充已实现的完整教学闭环。

界面以教师任务组织入口，减少内部术语：导入资料、检查切题、修订标签、选题备课、材料命题、预览导出。美化在流程与信息层级稳定后推进，不能用精美演示掩盖功能未贯通。

教师最新明确要求“每个功能都要有预览”。交互原则改为先选择资料、查看原文及候选结果、勾选/修改，再确认保存；导入后才能看题不能替代导入前预览。知识蒸馏应并排对照原文与提炼结果，补答应对照题面与解答，组卷/课件应查看实际输出页面，变更后重新预览再导出。取消不加入个人题库；当前全功能尚未达到这一统一标准，须逐入口补齐并实测。
