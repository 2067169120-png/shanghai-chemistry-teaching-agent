# 保存、交付、备份与遇到问题

**维护源码的知识与例题关联：** 在关联窗口的“导出与恢复”保存独立JSON，换电脑时单独带上；先检查新增、重复和冲突，再明确恢复。现有备课ZIP与教材备份不包含这些关系，关联JSON也不复制教材或原Word。[保存与恢复关联](lesson-and-paper.md#knowledge-example-relations)。

## 下次接着做：先分清四种东西

| 要保留的东西 | 应做的操作 | 不应混淆为 |
| --- | --- | --- |
| 可继续编辑的备课 | 保存草稿，在“我的备课”搜索并重开 | 只留下导出的 PPT 或 PDF |
| 最近成功落盘的编辑 | 使用原恢复副本，确认内容再继续 | 每个按键都已经保存，或原图也被备份 |
| 要打印或发给同事的文件 | 导出明确版本的独立副本，打开核对 | 全部业务资料已迁移 |
| 考试、作答和复测记录 | 在各自页面完成保存／正式登记并重开核对 | 全都包含在备课 ZIP |

### 准备什么

确认当前作品、输出版本和保存目录；准备可写的备份位置，保留唯一原件。升级程序前先保存当前编辑。

### 怎么做

“我的备课”可按作品名称或原课题搜索，再区分当前、归档和回收站。重命名主要改变显示名称；回收站中的作品先还原再打开。查看历史结果不应触发重新收费生成。

备课改完点“保存草稿”。成品有修改时生成新版本，再用导出所选版本交付；维护源码按钮为“导出所选版本的全部文件…”。Office中改了副本，不会自动回写教学环节或页面编排。

**维护源码知识卡：** 已加入课件的摘要正文、来源原记录与所选版本随备课草稿、恢复副本和普通备课ZIP保存；关联裁图随所引用图片保存。继续从知识卡读取原页或选图仍需本机原教材及当前目录，原书不在普通备课ZIP中。个人教材工作区与完整Word库需各自保存／备份，恢复知识卡不代表这些资料也已迁移。[知识卡操作](lesson-and-paper.md#textbook-card-handoff)。

**维护源码完整题课件：** 已接入的题面、共同材料、教师答案、原图及来源版本随作品草稿和恢复副本保存；登记的旧版与新成品可纳入备课ZIP。继续从题库选新题仍需要完整Word导入库，普通备课ZIP不含该库或原教材。本轮持久候选同时保留Word库与备课作品，换机时要分别保管。[接入操作](lesson-and-paper.md#library-card-handoff)。

**2026-10-07讲义选图：** 原图所在目录因恢复备份而改变时，同一Word版本与原图仍可继续使用；来源记录保留原位置，读取当前副本并核对文件与图像摘要。同图同用途不因路径改变而重复加入。继续通读、搜索或选择其他原图仍需保管完整Word库；普通备课ZIP中的已用图片不等于完整讲义。[操作](lesson-and-paper.md#classroom-purposes) · [验收](../qa/2026-10-07-lecture-image-reading-qa.md)。

**前片持久候选：** 讲义原图、问题标题、完整课堂文字、关系图、点击设置、框架与Word讲义选项随草稿及恢复副本保存。实际恢复44草稿／264成品／70引用图摘要，原42稿及252成品保持；CMD重开48素材／2完整题／27输出版本／8点击素材和讲义选项通过，实际PowerPoint读回16点击效果。继续选新讲义图需保管完整Word库；105页原教材、9节、3笔记与PDF54由教材专用ZIP保存，普通ZIP不含Word库、原书、阅读位置、设置或密钥。[操作](lesson-and-paper.md#classroom-purposes) · [验收](../qa/2026-10-06-handout-maps-and-classroom-images-qa.md)。

**维护源码逐页讲稿：** 在实际PPT预览中先应用讲稿或正常返回，再保存备课草稿。应用后的讲稿按所选课件版本分别保存，随原恢复副本及备课ZIP恢复；未应用且窗口异常退出的输入不保证恢复。讲稿不改原PPTX，也不导出音频；本机声音与语速设置不随备份迁移。恢复需使用支持逐页讲稿的维护源码，Office和SAPI声音依赖另行准备。[讲稿操作](lesson-and-paper.md#lesson-narration)。

### 得到什么与完成检查

关闭后重开草稿或分析，检查材料、版本和任务记录；打开每个交付文件，确认是本次所选版本。发给学生前分离教师稿和学生稿，检查图片与讲者备注中的答案和隐私。

维护源码中的“导出进度 JSON”保存当时的题库检查报告，含来源名称与题面摘要；它不备份原题或教学标签。整理与保存标签请按[Word 待办操作](lesson-and-paper.md#library-review)回到原题完成。

## 准备换电脑：先核对备份范围

在备份窗口阅读范围选项、缺失清单和外部修改提示。v0.1.101 中勾选“包含已结束任务与成品”可纳入原草稿／恢复副本中登记的教案、PPT 和学习单；不是扫描磁盘上所有同名成品。

**未启用带源选项的备课 ZIP 不包含原Word完整题库；所有备课ZIP均不包含学生作答／批次／批改暂存、API密钥、Office或字体文件。** 这些需要另外按各自目录保存。只导出考试HTML报告，也不能恢复全部考试与原件。

**0.1.103的带源备份：** 勾选“包含本课原讲义及同批原文件”，并明确原讲义所在个人工作台目录，可将课程引用的已登记讲义及其完整导入批次一同保存，恢复后继续选材；本地98份原Word的带源恢复已验证。未勾选时仍只保存课程材料和来源引用，教材原PDF、未引用批次、学生作答、考试与复练需分别保管。前文关于不含原Word的限制适用于未启用此选项及旧版备份。

先恢复到独立目录，检查草稿、关联图片和三类成品能否打开，再决定后续迁移。缺少原件时先补回明确原文件，不能把“有引用”当成“文件已恢复”。不要删除旧电脑的唯一副本。

**维护源码页面编排：** 草稿与恢复副本保留完整素材、原始快照、阅读顺序和页面位置；备课ZIP可纳入已登记的教师／学生DOCX、PPTX、PDF六份成品及旧版本，仍须勾选“包含已结束任务与成品”。环节关联、源快照、独立副本选择和已编辑内容随草稿保存，恢复后源环节变化仍须核对。行内图的位置与上下标依据随草稿保存；关联图片随备课图片备份。个人教材图和笔记的作品副本可恢复，个人完整教材及研读进度另用教材专用备份；原Word及正式五册外部PDF须另存；未登记的成品不会自动扫描入ZIP。恢复需使用支持页面编排的维护源码，旧v0.1.101包尚不支持。[操作与输出范围](lesson-and-paper.md#lesson-composition)。本片隔离验证的17版102登记文件已逐文件恢复一致；这个数量只描述验证作品，不改变备份范围。[当前验证](../qa/2026-10-05-narration-workflow-slice-qa.md)。

### 教材裁片回执与原书搬迁（维护源码）

备课ZIP按本次支持的备份范围，自动纳入草稿、恢复副本及已选入备份的已结束任务正文所引用、且唯一通过核对的教材裁选回执，不打包全部回执。即使未勾选 **包含这些备课引用的本地图片**，这些有效回执仍会保存；要恢复图片本身仍需勾选该项，原教材PDF另行保管。缺失回执会列入清单；有重复凭据或来源绑定不一致时，须先核对后再备份。

原书换了目录后，保留原资料库登记信息和同一原PDF。在课件中选中裁片，点 **对照教材原页…**，核对保存时与当前资料库的位置，再点 **关联并打开原页**。只有同一原书通过核对才可关联，同名文件或不同内容不能替代；确认前取消、关闭或换课不保存关联。这份位置记录只留在本机，不改原始来源、不进入备课ZIP；在另一处恢复后需重新确认该机位置。[具体操作](lesson-and-paper.md#course-source-continuity) · [当前核验范围](../qa/2026-10-09-course-source-continuity-qa.md#course-source-continuity)。

个人桌面状态默认位于 `%LOCALAPPDATA%\ShanghaiChem\DesktopWorkbench`，实际运行目录及工作区可不同。不要把私有资料放入程序的 `_internal`，也不要把全部私人目录上传公开 issue。

## 清理可重建缓存（本轮维护源码）

在 **设置 → 缓存维护** 点 **查看缓存**，选择 Word 原生预览、Word 目录／检索或首页资料统计，再点 **清理所选缓存**。窗口列出文件、字节、索引记录和逐项结果；正在使用、计划后发生变化或无法核验的文件会保留。后台任务完成后可重新查看。

下一次检索或刷新会从原资料重建目录。原 Word/PDF、教师标签和题目范围、已选题、学生资料、考试、费用账本与导出文件保留。SQLite 只清已核验的可重建行，历史观察记录和数据库文件保留，文件大小不一定立即减少。此入口用于维护缓存，换机仍按上面的备份范围准备资料；上方已发布 v0.1.103 包尚无此入口。

## 按现象排查，不从清空数据开始

| 现象 | 先做什么 | 此时不要做什么 |
| --- | --- | --- |
| 题库没有结果 | 清除过窄筛选，检查来源与导入记录；维护源码可从首页“题库与教材状态”打开“检查本地题库进度” | 认为程序自带全部教材；重复导入全库 |
| 题库进度显示“暂不可读” | 点击“刷新目录”，等待重新读取后继续；保留原资料 | 把读取失败当成 0 条待办或清空资料 |
| 保存标签后仍有待办 | 核对剩余缺项，关闭原题窗口回清单等待更新；原考试缺少依据时仍保留“待确认” | 为清空待办而猜填，或把取消、保存失败当成已经完成 |
| 找不到手册中的按钮 | 查看运行版本；“维护源码”入口不在旧试用 EXE | 以为自己的资料损坏而重建档案 |
| 朗读不可用或化学读音不合适 | 先编辑并保存讲稿，检查本机中文声音；用物质名称与文字条件改写口播内容并自行核听 | 把静音状态测试当成音质验证，或为朗读反复发送题目给模型 |
| 实际PPT提示PowerPoint正在使用 | 先保存并自行关闭PowerPoint窗口，再重试；预览会显示实际转换引擎 | 结束所有Office进程或把未完成转换当成可用成品 |
| PDF 无法分页 | 查看“本机检查”的 Office 发现结果，核对最终文件 | 把快速图片预览当成实际分页已验收 |
| 停止后提示清理尚未确认 | 保留完整提示，先保存自己正在编辑的其他Word文档；本次结果暂不使用，等待或按提示核查转换状态 | 把停止等待当作转换已成功；通过结束所有Word进程排错 |
| 原图不见了 | 保留草稿，按来源定位或补回原图 | 清空草稿；认为恢复文字就能恢复文件 |
| 提示旧建议或任务过期 | 查看变化的成绩、材料和任务依据，按页面重新核对 | 反复重算统计来强行解除提示 |
| 另一个窗口已保存 | 保留当前输入，重开最新记录后对照处理 | 用旧窗口强行覆盖最新工作 |
| 模型请求失败 | 查看接口、能力、发送范围和预算；先保留手工内容 | 反复整批请求；将文字联通当成识图正确 |
| 题篮读取失败 | 保留原资料，按提示重试或核查文件状态 | 把错误当成真正空篮后覆盖保存 |

### 反馈问题时提供什么

提供运行版本、所在页面、复现步骤与完整错误提示；截图先遮住姓名、学号、密钥和私人路径。“本机检查”的报告可用于说明环境，但不证明真实课堂效果或所有图像识别质量。

## 日常快捷操作

Ctrl+K 搜索功能和教学模板，Ctrl+1～5 切换首页、题库、组卷、学生分析、备课；F1 打开使用帮助，Esc 返回对话框。新版帮助可按“备课、打印、讲评、改分、备份”等词查找操作，阅读帮助不会发起模型调用。
