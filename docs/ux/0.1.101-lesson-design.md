## 两处可用连接

1. 已有完成任务通过原哈希核对的revision_source读取，按原教学阶段、关联活动和评价生成可选环节。加入前显示全部转换字段、原任务/版本和待核对事项。只追加选择内容，保留已有教师环节、输出、原任务及原图；精确文字复用目标，不按粗标签猜覆盖。来源和目标设计变更后重新预览，同一版本不重复添加。
2. node-exports三类成品通过已保存草稿、恢复副本或选入任务中的正式版本记录枚举，按需随原备课ZIP携带；不扫描任意目录。按原哈希核对，缺失列清单、修改提示核对。恢复独立工作区后原三类文件可打开，实际PPT预览可重建；缓存不打包，原题库/学生/考试仍不在范围。

## 内容与课堂边界

新增环节全部待教师核对，材料/图片默认锁定且仅教师可见。独立PPT页正文不伪造成学生任务。复杂图表结构保留教师参考和原稿，不宣称保真转换所有表格、公式或装置；同页被多环节引用可能重复，需整理。目标状态不是自动语义判定或掌握度，用时沿用初稿估计。默认课堂作用为解释与建模，教师应按实际调整。

原API生成入口和本地稿件修订入口均保留，本版转换无新的模型调用。AI限定节点字段修订、真实题目对象无损关联、局部页刷新及外部Office改稿回写尚未完成。备份新路径扩展需0.1.101或以后支持版本恢复，新版仍可读旧ZIP。
