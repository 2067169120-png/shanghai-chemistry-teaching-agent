# 0.1.100 教学设计联动：范围与验收

日期：2026-09-18。接续Issue #24 B01—B05。原Windows/PySide6、草稿、恢复、图片存储和PPT渲染器继续使用，不另建题库或学生库。

本批实现本地教学环节、逐目标活动/评价关联、材料锁定、三类文件同源导出及成品过期提示。新增`lesson_design`为原备课payload的可选字段，旧草稿默认无此字段；新字段不偷偷注入原AI请求。原模型生成/逐项修订保留，AI局部节点改写仍待接入。

## 对应旧任务

B01第一批：原生双栏节点/属性编辑，细分页签，增删调序/撤销重做，目标与材料独立页签。不是已完成的三栏拖拽图形画布。
B02第一批：本地题目、教师答案、图片及可见范围锁定，普通解释修改不改变锁定内容；没有真实API局部修订验收。
B03第一批：目标逐项关联学生任务、产出和评价，经教师明确确认显示“已明确关联”。无任务或无证据只待核对。修改目标/任务/材料/评价后重核。不是语义自动审题或掌握度判定。
B05第一批：同一节点顺序与素材投影至教案、PPTX、学习单；修改后旧版本标为需更新、另存新成品。全套重生成，不是逐页增量渲染；外部Office改稿不回写节点。
B04第一批：读取实际PPTX经LibreOffice Impress转成PDF、原生逐页查看，明确引擎。不是PowerPoint COM或全部Office版本一致性保证，也未完成原计划20页复杂化学黄金集。

## 成品与资料

新增node-exports在原preparation-v1任务目录下，以OUT标识保留不同版本，不覆盖旧文件。三类成品引用通过路径和哈希核对。节点数据随原草稿/恢复保存；原备份可携带节点字段及图片，但旧任务备份枚举没有覆盖node-exports目录，恢复后需另存/拷贝三类文件或重新生成，不能标记为全成品迁移。

材料从原备课明确引用，默认教师可见，教师需核对后用于学生页。纯文字快照保留原内容，但不宣称保真复制所有Word对象。长学生材料不截断成残题，而是提示拆分；保真组卷仍使用原服务。图片通过原图片存储核对并同时写入教案、学习单及PPT；教师答案只在教案/PPT备注。

本地64项核心/原草稿/备课测试通过。第一次集合误包含依赖PySide6的旧UI模块，因环境无PySide6在收集阶段失败；随后核心集合通过，不把排除Qt用例称本地原生通过。本地样例的DOCX通过标准render_docx脚本渲染检查，实际PPTX经LibreOffice转换。新Windows探针验证实际入口、双目标缺一项、补任务、锁定、调序撤销、三类输出、旧文件保留、恢复/草稿重开、原图字节及800×700可达。
所有数据为合成，无真实学生、付费模型、教材蒸馏或用户题库重导。
