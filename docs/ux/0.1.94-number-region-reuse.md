# 0.1.94：题号位置复用与答案分页

## 教师操作

第一次：混合组卷 → 调整图片题号后预览 → 框选/添加 → 记住此图位置。下一张卷：载入已存位置 → 核对当前新号 → 添加替换 → 两版真实PDF预览。忘记位置不会删除当前替换，撤销当前替换不会撤销明确保存的位置；界面分别说明。

## 数据与对应

新增 `desktop_number_regions.py`，使用现有DesktopStateStore的原子更新，仅向`scan_number_regions`写入哈希、尺寸和区域。读取与打开对话框不写状态。图片字节/尺寸变化不复用旧框；保存失败保留旧记录，仍可继续手工排版。存储不是另一套题库，旧备课备份当前未扩展此项。

`build_mixed_paper_docx`通过可选参数收集实际生成块的图片与编号计划对应，不修改原有返回字段。仅能唯一归属单一Word印刷题的图提供本卷号码建议；共有材料或多题归属包括一个未知值即不建议。不同顺序重新编排时重新生成对应，不使用图片名、OCR或模型文字猜编号。图片内部引用仍需教师指定目标号。

单张图多区域逐一核对；不同题重复相同图需不同新号的逐实例写图，尚未解决。位置保存仅减少重新拖框动作，不意味着旧框每次都可免核对。

## 分页修复

`desktop_answer_layout.py`只对导出克隆设置段落分页属性。生成的答案标题与下一块相连；简短首段和最多三段空行连到首个图/表/正文。首图和长答案不与后文整段锁定；显式分页不删除。表格不把所有行设为同页。依据python-docx官方段落分页语义：
https://python-docx.readthedocs.io/en/latest/dev/analysis/features/text/paragraph-format.html#page-placement

在旧0.1.93实际PDF重现“答案标题与图跨页”，在新代码生成DOCX并用LibreOffice渲染后核对两页。PDF探针检查两个可搜索的答案首段与对应图像对象所在页；这些是合成样例断言，不代表全库版式。

## 测试与限制

局部69项已有回归与22项新增非Qt测试在本地通过。当前环境无PySide6，安装因网络解析失败，未把本地检查称为Windows/Qt通过。源码窗口、真实鼠标/保存/重开和同一EXE验证由本版Actions运行；最终数量只取一次完整运行，失败和子集不累加。

无OCR、真实模型请求、用户教材读取或题库重导。原图、文字、公式、作答区和来源身份不改；最终文件生成后仍需教师确认。各个Windows系统缩放、多屏、真实长答案和全部复杂原题尚需实际试用。
