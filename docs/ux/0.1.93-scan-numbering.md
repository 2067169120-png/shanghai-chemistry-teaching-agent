# 0.1.93：补齐字体修复与扫描图号码

## 与0.1.92的关系

0.1.92是未发布候选。其第一轮Windows化学符号检查失败，不把该结果改写为通过。0.1.93在正常授权分支中重新核对并实现符号回退、应用初始化幂等和发送确认留白，保留既有字体覆盖检查，不分发字体文件。当前字体的实际来源可在本机检查中看到。

## 图内换号范围

在已经生成的两版DOCX中枚举图片，以原内容哈希绑定区域。教师框选原图坐标，填写本卷号，软件只在导出副本内替换白底数字；框外解码像素完全保留，JPEG改写副本保存为PNG避免额外损失。只更新图片媒体及对应Content Type；Word文字、上下标、公式、图片位置和大小不改。软件自己插入的旧提示更新为“部分区域已调整”，不谎称所有号码已处理。

同图在两版和同版重复出现会共用修改，不能逐实例设置不同号。教师专属答案图仍只在教师版。未选区域、不支持格式、旋转标记和图内引用不猜改。本次标注不会写回题库；调序后新预览必须重新核对。此版本不是自动扫描拆题或全题库的永久号码模板。

## 教师工作流

先确定题序，通过混合组卷页的图片题号入口打开选图。看上下文与版别，框住旧号，添加替换。可撤销、移除、清除与对照原图。最终回到已有PDF分页确认和导出流程，保证导出来自实际查看的文件，不在确认后重算。

## 验收方法与边界

新增纯函数测试覆盖PNG/JPEG/BMP框外像素、两版一致、答案隔离、无修改字节一致、重叠/越界/错图拒绝和数字变更。Qt测试用真实鼠标坐标检查框选与撤销，在800×700检查主要操作可见。实际桌面探针导入一份包含两道乱序扫描图及答案的合成Word，经真实题篮、新入口、两版分页与导出；整页图直接取分页产物，不拿被窗口裁切的截图代替完整页面。

最终测试数量与源码提交以本版readiness/package报告为准，早期字体14项和本地纯函数测试属于重复子集，不累加。扫描图端到端样例是Word中嵌入的位图；并不证明用户公众号所有跨页、旧裁片、灰底、竖排或其他格式已验收。未调用真实模型、未重导用户题库。新样例不是学校真题。

## 实际返工

初轮41项字体/区域/原生交互测试通过，但完整DOCX→PDF失败。已在本地用相同PNG和JPEG文档配对复现：图片类型清单使用新命名空间前缀时LibreOffice不读取。改为保留原OPC默认命名空间后，两种文档实际转换成功；新增对应格式回归，不删除旧断言，也不让软件在转换失败时给出假预览。

Issue #9继续完整题库迁移；Issue #14继续多实例号码、持久框选、自动建议与复杂版面；教学节点编辑和学生原作答评分同屏另按原路线推进。不要为了本版增加云上传、OCR推测或另一套选题库。
