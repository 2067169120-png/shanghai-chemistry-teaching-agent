# 0.1.96 单份作答同屏复核

## 实现与入口

StudentReviewDesk复用原ReviewItemCard验证器和record_student_score/record_student_diagnosis接口，不另建学生库。主学生页顶部固定入口可打开已载入的原分析；只处理一名学生的一份作答，班级批次选择继续留后续。新增投影字段展示原已有评分理由、诊断备注和有界证据锚点，不重写AI原始返回稿。

ReviewPageViewer后台解码QImage，主线程显示QPixmap；按student/submission/file/hash读取完整页面，过期回调不能覆盖新题。区域需满足原页面角色/哈希及有限归一化坐标，未知匹配不默认显示其他题。框为AI定位而非教师真值；可手动查看同类其他页保留公共材料。每题记录角色/页码，不承诺缩放及拖动位置保留。

## 教师决定

未记录输入按match_id在窗口内保留；只保存当前提交组，其他题及未提交诊断字段保留。显式记录沿用源revision与追加式历史，旧记录冲突拒绝，不写到其他学生。刷新保留输入并展示新保存状态。退出有未记录输入可取消；保存中不能关闭。该窗口无持久自动恢复，已保存决定仍由原存储保存。

新评分留空、诊断默认待判断。缺少评分不算0。已保存分数修改后诊断沿用原过期标记；旧模型建议、教师原因、最终诊断分开展示。当前统计不冒称班级汇总。

## 验证

新非Qt15项与既有30项合计45通过，本地因没有PySide6排除1项原UI用例，未删断言。原首次尝试该UI用例因缺包失败，日志保留。Windows第一眼流程对真实主入口、原图、证据框、改分、保留另一题输入、诊断、重开和紧凑窗口执行，再由完整Windows/独立EXE工作流验收。

夹具仅使用两名合成匿名学生、每人两题和六页人工构造的PNG，原管理器接收注入的固定传输返回稿：两次本地假传输用于建样例，复核期间调用数不增加，网络请求为0。正常应用不加载这个夹具；它只由显式验收CLI启动。没有真实学生评分质量、班级效果、所有系统缩放或化学识别质量声明。
