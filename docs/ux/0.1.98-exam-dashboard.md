# 0.1.98考试分析：数据与模型分工

普通xlsx只读保存值，明确表头及列映射；使用轻量标准库读取必要SpreadsheetML，不加入桌面必装大型数据服务。模板通过artifact_tool生成，仅合成数据。工作表坐标、公式缓存与错误值分开处理：缓存可能过时，教师应先重算保存；读入不执行公式或宏。

本地统计不依赖API：总分分母排除缺考、缺失、非法分数与完整小题合计冲突。逐题统计只用该题有效分数并列出分母，明确0分计入、空白不计入。知识点以有效作答分值加权，单一主映射避免重复计分；无法从列标签证明不重叠，教师须核对。只有总分不做知识点结论。同场Excel内可班级筛选，不称跨考试进步。

试卷复用Word原生读入；PDF文字和整页渲染副本、图片均可查看。视觉请求单独核对配置/发送许可，文字API不被当作能看图片。接口沿用已存在的请求构造和PinnedVisualTransport，发送前显示完整资料，结果只作结构化建议，未知题号/学生拒绝，数值面板不接受模型字段。学生名字、班级名、文件路径和Excel原件不进入结构化数据，选入试卷/自由文字需教师自行脱敏。

历史快照为本机状态下独立exam-analyses记录，不写原学生业务或原题库。保存失败保留窗口数据；编辑试卷文字使旧建议失效，班级范围与建议绑定。保存/查看不再次收费。考试快照不在现有备课ZIP里，导出的匿名HTML不等于自动清除了自由文本中的个人信息。

验证以12条合成成绩（10个有效总分、均分69、中位数72）和四题映射为固定基准。源码和同一EXE测试实际入口、列映射、图表、热力表、Word共同材料、确认发送与固定本地传输、保存重开、匿名导出、紧凑布局。真实服务商API、真实学生、评分准确率与教学提分没有在本轮验证。

参考：Qt原生绘制 https://doc.qt.io/qtforpython-6/PySide6/QtGui/QPainter.html ；SpreadsheetML公式缓存语义 https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-formulas 。这些只支持实现语义，不是本项目端到端验收证据。
