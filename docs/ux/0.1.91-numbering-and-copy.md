# 0.1.91：本卷题号与教师界面用语检查

## 实际改动而非概念效果图

基于0.1.90的866a380f。用户本轮明确要求组卷后使用新顺序题号、逐页检查不自然翻译，并继续推进教师界面。本版沿用原生Windows/PySide6、题篮身份、Word/图片读取器、生成协议和数据保存位置。

## 编号规则

混合卷与仅原题库的组卷导出都先按本次选题顺序形成展示编号，再让学生版与教师版使用相同分配。题组标题、组内印刷题与内部作答单元分开；内部(1)、(2)、选项A/B和计算中的数值不做全局查找替换。Word导出只改克隆的OOXML文字节点，保留表格、公式、上下标和嵌入图。已识别的嵌套印刷题起点沿用题库标记；例题中的1/2实验步骤不重新分类。

主要覆盖27.、27．、27、 、第27题、【例题27】、例27、【变式3-1】、中文典例标签及自动列表首段。句中“第N题”只有在当前选择能唯一定位到同一来源的编号时更新；不存在、重名或图像中的引用不乱猜；OMML公式节点保留不动，公式前后的普通文字引用仍按同源映射更新。教材化学条件如27.25 mol/L、2H2、25 ℃以及数字上下标不改。异体标签和复杂手工范围还需教师检查。

原卷和个人图片主题在外部使用新号；**像素中旧号没有移除**。保留原图字节，向预览和卷面传递明确提示。需要下一批的原图题号区域标注、预览和可撤销修改，才能做到此类图片没有旧号。本版没有OCR擦字，也没有声称“全部题号已彻底修好”。

文案记录见[逐条对照JSON](0.1.91-copy-changes.json)，两轮共164条修改记录，涉及25个界面文件；记录中的行号是相应修改前位置，不保证为最终行号。有些内容经历两轮修订，不能把记录条数冒充独立功能数。首次盘点提取886条常见UI字面量，这是候选清单，不等于所有后端动态错误和第三方窗口完成全面本地化。

新增Qt翻译器使用已安装/已打包的qtbase_zh_CN.qm，保持译器生命周期，一次加载；不打包系统字体。业务模型、API协议、json字段、题号身份和化学原文没有为美化而批量改名。改文字不降低老师确认、数据完整性或模型收费提示。

## 最小验收

乱序选择原38/27题，学生正文为1/2，教师答案同序，“第27题”变为第2题，12.5不变；本机导入源文件不改，学生版无答案。分别检查最终DOCX与由Office转换的PDF。混合原卷按印刷题递增，图片字节保持一致且限制明确。备课800×700滚动到底仍可保存和生成，资料导航不改选区；失败但有返回结果仍可查看而不自动重试。最终机器结果与源提交见本版QA文件。
