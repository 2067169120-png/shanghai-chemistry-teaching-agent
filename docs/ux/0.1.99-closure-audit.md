## 3. 本轮新增功能的操作与实现

### 3.1 已有正式评分直接进入原考试面板

`WorkBatchDialog.open_summary`调用`desktop_batch_exam.collect_batch_exams`，只读原学生作答和正式评分。相同原题页内容、题号、满分及参考答案来源才合组；共享一个班级名并不代表试卷相同。每一格保留原作答、match、评分版本和情况记录。

未评分、待核对、缺页、未作答、尚未学到、图像难辨不补零，模型建议和暂存不参与。部分小题有效仍可统计该小题，但缺少任一所选单元的有效分数时不生成该学生的完整合计。整体口径是“所匹配评分单元”，不能冒充整张原卷总分。

快照生成后继续改分，要从批次重新读取。知识点不从低分推断；60%/85%参考线仅帮助本次分布阅读，不代表官方等级。多个同卷组由教师选择，不合并不同试卷排名。

### 3.2 考试复练调用原题库与原组卷链

`ExamFollowupPanel`保存考试内任务，通过`TeacherWorkbenchWindow.open_exam_practice`进入已有选题中心。教师选择来源真实知识标签，原图文阅读器核对完整题目后入篮，再返回任务明确勾选要关联的项目。

`desktop_exam_followup.practice_request`只传任务勾选的题篮项目，沿用原预览、学生/教师版分页、确认及实际导出。源身份、修订、题篮指纹变化时要求重新核对，不静默换题。不根据API写出的题号伪造题库命中。

这是一条教师选择和核对的路径，不是已完成的自动个性化推荐排名。新任务入口尚未嵌入图片旧号区域编辑；复杂扫描题仍需原混合组卷入口核对。

### 3.3 复测以实际记录收尾

`record_attempt`保存真实日期、状态、实得分、实际满分、说明和当次练习引用，采用追加记录；完成状态要求实际分数及依据。未做/缺资料不记零，未来日期不当实际发生。当前概况取每生最新录入，原考试分数不被覆盖。

记录随`ExamStore`的考试文件保存，读取旧考试没有新字段时仍可使用；写入有版本检查，不覆盖另一窗口较新任务。HTML仅导出当前班级范围的任务对象，姓名隐藏不等于自由文字已脱敏。它不是跨卷等值分析，不能直接相减宣称因教学提升了几分。

## 4. 原59项清单的收口方式

保留原A01—H05共59项，不删未完成项，也不把拆细验收项再加进同一个完成率。E03目前是“真实标签选题/明确关联”，自动错因匹配、难度依据、重复控制仍未全做；E04有考试内任务和真实结果，尚未回写统一长期学生档案；E06从独立Excel统计扩展到原批次正式评分同卷快照。B01—B09、C02—C09、D03等不得因此自动变为完成。

## 6. 下一批按教学价值排序

第一优先：完整教学节点编辑及同源教案/PPT/学习单联动（B01/B02/B03/B05），同时让实际PPTX预览成为交付核对入口（B04）。此前工作已较长时间集中于保存和考试，不能继续无限扩展统计附件而放任备课主流程停在长表单。

第三优先：资料导入异常就地修复与全业务备份（C02/C03/C05/A08/X09），真实教师样例验证恢复后能选题、批改和重开，而不是只看到记录数量。

装置、有机图与热点完整命题按G05—G07单独推进；优先结构化对象和可编辑输出，不把任意生图结果当化学真值。真实题库蒸馏和教材标签仍由本地资料支撑。
