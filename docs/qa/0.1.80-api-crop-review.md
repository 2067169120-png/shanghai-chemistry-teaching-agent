## 检查覆盖

- 用户明确输出值高于32,000或低于旧默认时，实际Responses/Chat请求采用该值；清空保留既有默认。输入超出本机估算预算时零传输，不静默截断文字或图片。
- 旧配置缺少字段时只读兼容；修改限额使旧发送确认失效，不读取或改写密钥。Word标签预览与实际调用采用相同限额，带图尺寸来自实际像素。
- 每次视觉提取后，对冻结原页和实际裁片逐组复核；17条证据对应1次提取和3次复核（8/8/1）。错误哈希、漏项、重复、不确定、拒绝、空返回及取消阻止该分片作为完成结果进入个人候选库。
- 提示词覆盖选项、有机图、装置图、图例、答案续行和共同材料；这只证明规则进入请求，不保证用户模型正确执行规则。
- 显式共享材料按题目关联展示，同证据去重；完整主题备课仍保留所有共同图文。只剩答案图不能充当题面。
