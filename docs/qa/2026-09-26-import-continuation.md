SQLite 不直接打开个人数据库路径。工具先拒绝任何 WAL/SHM/journal sidecar 以及 WAL 模式数据库，再将哈希绑定的主库字节反序列化到内存并开启 `query_only`。这避免了 SQLite 即使使用 `mode=ro` 仍可能更新共享内存的行为；工具不会为继续执行而忽略 WAL 中的最新标签。

缺文件、原件与清单不符、缓存过期、题键重复、来源范围修订过期、属性无效、输入在运行中变化或已有输出目录，均失败退出。所有输出先写本次临时目录，输入再次核对后才发布完整结果，不覆盖旧报告，也不在失败后留下看似成功的目标目录。
