# A07验收范围

范围：草稿和已结束的生成任务、类型限定身份、名称/原课题检索、当前/归档/回收站、还原位置、先筛选后分页、过期操作拒绝、当前未保存表单独立保护。没有物理文件删除、备份恢复、云同步或真实模型请求。

本地非Qt回归136项通过（含新增26项）；PySide6在本地不可安装，界面检查由Windows任务执行。首次扩大本地命令包含一个不存在的测试路径，未执行测试，改用实际存在的文件后运行成功。Windows最终测试集合与实际通过数量以同版本JSON报告及JUnit为准，不与本地重叠集合相加。

首轮Windows源代码362项通过，原生截图完成。检查打包验收脚本时发现它错误依赖教学模板覆盖已有课题，而模板按设计保留已有课题；验收脚本已显式编辑合成课题，并增加存在旧课题/草稿时运行完整整理流程的回归。第二轮362项通过，新增用例因合成草稿未填材料而在准备阶段失败；已补齐测试材料，不放宽正式草稿校验。首轮及失败运行保留在Actions；最终以同版发行报告为准，不相加。

窗口截图与程序输出使用合成资料。设置及八个主页面继续复用上一版本的检查；额外在源代码和相同发行EXE中点击重命名、归档、移入回收站与还原，核对草稿、任务文件、恢复文件和当前表单不变。单独回归500份以上记录中最早作品的搜索、活动任务与外部重试行为。较窄窗口保留纵向滚动，底部操作可能需要向下滚动；未宣称所有控件在800×700首屏同时显示。

这不是所有Windows配置、现实题库规模、多屏或课堂验收。实际PPTX的Office视觉一致性仍未完成。软件包保留Windows版本身份，不分发字体、题库或密钥。
