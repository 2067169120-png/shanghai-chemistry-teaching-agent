# A07验收范围

范围：草稿和已结束的生成任务、类型限定身份、名称/原课题检索、当前/归档/回收站、还原位置、先筛选后分页、过期操作拒绝、当前未保存表单独立保护。没有物理文件删除、备份恢复、云同步或真实模型请求。

本地非Qt回归136项通过（含新增26项）；PySide6在本地不可安装，界面检查由Windows任务执行。首次扩大本地命令包含一个不存在的测试路径，未执行测试，改用实际存在的文件后运行成功。Windows最终测试集合与实际通过数量以同版本JSON报告及JUnit为准，不与本地重叠集合相加。

窗口截图与程序输出使用合成资料。设置及八个主页面继续复用上一版本的检查；额外在源代码和相同发行EXE中点击重命名、归档、移入回收站与还原，核对草稿、任务文件、恢复文件和当前表单不变。单独回归500份以上记录中最早作品的搜索、活动任务与外部重试行为。

这不是所有Windows配置、现实题库规模、多屏或课堂验收。实际PPTX的Office视觉一致性仍未完成。软件包保留Windows版本身份，不分发字体、题库或密钥。
