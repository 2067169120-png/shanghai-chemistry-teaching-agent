# 2026-10-03 Windows教师端差距补全

本次范围来自用户“手机端功能不用做，然后其他差距继续补全”。手机提交与反馈从实施范围排除；本次接续已有教材题库融合源码。手机相关历史视频仍是参考材料，不代表后续需要实现。

## 已实现的增量

| 对照差距 | 本次行为 | 验收边界 |
| --- | --- | --- |
| R07 名册、应交名单与提交队列 | 稳定成员身份、CSV预览、建单冻结名单；逐人登记收交并明确关联实际作答；相同作答范围可重开原批次 | 重名不自动合并，未知与缺交不记0分，班内编号和档案关联须教师核对 |
| R07 Excel映射与考试身份 | 列映射方案命名保存；工作表、表头行和列布局先对照再应用；考试行逐一关联名册，可分班保存 | 表格布局变化时阻止自动套用；考试行关联不改得分，不推断跨考试身份 |
| R09 正式评分与历史分析 | 原评分、登记条件或批次版本变化时标记历史快照；阻止沿用旧建议与复练输出；明确重读生成新分析并保留旧记录 | 本次覆盖作业批次正式评分到考试分析；跨全部作品的影响传播仍需扩展 |
| R11 业务备份恢复 | 所选已归档个人记录、原页、评分链、考试复测、教材题库和知识资料进入扩展清单，补齐激活目录登记的原书文件；SQLite保存一致快照，校验后恢复到新目录 | 程序、设置和密钥不纳入；外部自选位置原件与成品仍需另存；不能当作所有磁盘文件已迁移 |
| R16 教材图表与附录入口 | 在备课选材窗口浏览素材目录，按关键词定位精确原书页；保留整页候选与待核对说明 | 原页索引未裁图，不自动入选、不调用模型、不提升人审和使用权限 |

教材素材适配与目录源码从本机正在整理的独立知识工作区整合，保留来源文件和检查点；本次不归入新增化学研读。源教材、题库数据、真实学生资料、截图和本地备份均未随Git源码上传。

## 本机证据

- 新增及直接相关14个测试文件在独立进程完成237项；后续真实资料兼容修复追加备份、启动路径与既有Word生命周期检查。按测试类名与用例名去重，本轮不同用例427项末次均通过，失败/错误/跳过0；重复运行不累计为新增用例。
- 测试覆盖同名隔离、名单快照、实际作答归属、免交分母、版本冲突、分班关联、变化表头阻断、旧评分阻断与重读、SQLite WAL、取消与禁止覆盖、路径及归档攻击、独立恢复再备份、教材来源哈希、附录页界与迟到回调。
- 本机五册645页原书核验；319条素材目录均经明确原页读取成功，包括30个无编号节的补充栏目锚点和4个无父章的附录锚点。目录读取本身仅列元数据，选择原页才验证PDF字节、来源SHA与页数。
- 8幅实际Qt offscreen截图已查看：名册、收交、列映射、扩展备份、旧评分提示（学生页与总览）、素材目录和实际附录原页。学生、班级和成绩均为合成数据；原教材截图只保存在本机。
- 真实资料完成独立备份与逐文件哈希恢复：25,153个文件、约5.02GB未压缩，包含5个按目录原路径保存的原书。个人原状态保持；本机的名册与真实学生域没有现成记录，相关业务恢复采用隔离合成记录验证。源目录里的依赖链接被剪除，原始来源JSON中的重复说明字段保留字节，审计布尔标志与真实密钥值分开校验。
- Python语法与新增核心模块Ruff检查通过。新增检查已接入Windows集成CI；云端状态须按本次提交核验，不能沿用上一提交的绿色状态。
- 云端既有Word生命周期合成检查连续两次在第一个PowerShell子进程的15秒启动预算处超时，本机26项通过。测试进程启动预算改为有界45秒，保留取消、发布、进程归属和关闭断言；此修复不改生产Word操作，也不代表真实Office版式验收。

本机证据目录为数据工作区的 `outputs/2026-10-03-windows-gap-closure`。所有测试使用隔离个人目录和合成传输器，无真实供应商模型调用；真实素材核验只读取本地文件。本次为Windows源码与离屏布局检查，v0.1.101安装包未重建，不代替人工多屏/DPI、真实Office复杂化学成品或化学内容人审。

## 仍需继续的差距

1. 逐评分点量规与答案版本、整批失败隔离及恢复；本次名册与收交不能代替这些功能。
2. 教案、PPT、学习单与主题卷的复杂化学内容、公式、结构和共享图形的真实输出验收；现有另一编排工作区的未提交修改仍独立保留。
3. 长期错题与三天梯度练习，以及跨全部输出的变化影响传播和外部文件重定位。
4. Windows新安装包、人工125%/150%缩放与跨机恢复验收；视频/TTS、化学语义图等桌面扩展仍按证据分模块推进。
5. 教材383候选的人审、23个非编号教材节点的题库映射、讲义流程缺项及固定知识评测。已有原页可读不等于内容已审核。

手机端不再作为第二阶段待办。
