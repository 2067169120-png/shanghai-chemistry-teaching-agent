# 0.1.86 第一批验收说明

## 数据与工作范围

以b6102d5f（0.1.85）为基线。恢复副本放在个人状态目录recovery/preparation.v1.json，与正式草稿分开。只保存备课表单中的可编辑字段及图片引用，不复制图片文件，不保存模型配置，不在恢复和查找时启动模型请求。

## 回归重点

501份有效草稿中查找最早记录并按ID载入；205份实际保存的合成任务超出旧上限后仍可查。检查稳定排序、分页、异步旧回复、被改写或失效ID。未完成表单、图片用途、课时和模板进入同一恢复payload。过时队列不能覆盖关闭时最新快照；原子替换失败时原副本不变；不可读副本不自动覆盖。

Windows脚本使用三个独立进程：第一次编辑不完整表单和图片，等待恢复副本实际落盘，随后由父进程强制结束仍在运行的编辑器，不执行closeEvent；第二次重开比对完整payload并保存正常退出前的最后修改；第三次重开再次比对。另验证8个主页面及501份草稿检索。所有数据位于隔离临时目录，正式草稿不因恢复被改写。

## 执行记录

成功执行的源码提交、测试数量、平台和截图SHA以[机器报告](0.1.86-phase-a.json)为准，不将不同尝试重复累加。

首次CI在准备阶段因Windows换行停止；改用Git标准字节并保留前后内容校验。第二次334项通过、4项新测试失败，原因是测试自身用系统默认编码读取UTF-8中文；生产读写本已显式使用UTF-8，测试已修正。第三次337项通过、1项旧题篮测试失败：后台持久状态先完成，Qt成功回调尚未更新按钮，测试就作了界面断言。现改为在原超时范围内同时等待状态和界面确认，保留原断言，不延长固定休眠或删除测试。之后重新运行整个定向集合。

第四次338项和性能对照通过，但使用os._exit的独立异常退出脚本出现一次0xC0000005原生退出，未获取当次崩溃栈，未计作完整通过。第五次增加原生故障与阶段日志，并改为父进程在已保存检查点后终止存活编辑器：三个进程的重开/正常退出验证全部通过，进程错误日志为空。该结果验证新的强制终止测试路径，不据此断言前次原生异常根因已定位或所有Windows崩溃已消除。

本地118项非Qt验证与Windows集合重叠，不累计相加。未在本地环境执行Qt测试，不用离线纯函数测试替代Windows界面证据。

## 性能

每个查询创建独立匹配器，复用本次教材目录与条件，没有跨查询缓存或缓存有效期。对基线源码执行1千、5千、1万条、383目录节点、各5次测量；以100组固定随机条件核对原新结果及顺序。p95为小样本最近秩，不是生产SLA；不含原图读取、Qt绘制或网络。完整样本见[性能记录](0.1.86-performance.json)。

## 未涵盖

本版不重做全部教学资料导入、化学审核、真实模型测试或全部导出排版。不承诺尚未落盘的最后约2秒输入、断电或磁盘损坏绝对无损；恢复图片引用不等于恢复已删除原图。未打包新独立EXE，未完成全部59项任务。既有的模型返回内容恢复模块保持不变，新的编辑恢复与它分开，并保留原模块回归。
