# 0.1.91 验证范围与尝试记录

测试针对本次组卷编号、中文文案和备课固定操作，并保留原恢复、作品、备份、选题和渲染回归。当前机器数量、操作系统、代码提交和截图来源，以0.1.91-readiness.json及0.1.91-package.json为准；本地与Windows重叠的测试不累加。

## 新场景

常见Word题号与示例标签、答案前缀、同源明确引用、重排顺序、多个印刷题、已标记嵌套主题、化学小数、自动列表编号、上下标与OMML、扫描像素不改且显示限制。备课保存/生成真实控件常驻，材料选区/滚动不变，失败但返回结果可查看，中文Qt按钮资源。

实际探针调用现有Word导入、题库目录、题篮和混合组卷服务。验证原38/27题选成1/2后两版题答对应，独立EXE环境用Office生成实际PDF页图；不是重新画一张看起来像试卷的图。旧备份重开和文档生成继续复测，无真实模型和用户题库。

## 过程记录

首轮尝试包含依赖未入库parallel_outputs/intake_batches_v2测试支持文件的视觉导入用例，无法收集；没有伪造该夹具。对应独立SyntheticTheme字节/图文导出测试仍执行，缺原支持文件的完整裁片导入场景不冒称已验收。

本地早期宽回归因旧测试断言期望“待教师复核”“候选”“返回备课继续编辑”等原文案失败；仅更新相应明确的界面文案断言，保留不重复请求、结果不丢失和资料不变的检查。一次试验在整套UI对象仍存在时重新应用全局样式耗时较长，停止该自建测试进程后，将中文翻译安装提为独立幂等函数；不在后置测试中重复改所有窗口样式。

首次单个测试用绝对路径从仓库外运行导致包导入失败，改从仓库根目录执行；不改应用导入结构。失败/尝试日志在本地核验记录中保留。

## 未完成的验收

图片像素内旧题号与图内引用尚未自动重写，表格中的复杂多题布局和所有非标准标签仍需实际源材料检查；不是全库题号无误声明。结构预览仍不替代实际PPTX的Office一致性检查。Windows离屏/独立目录运行不等于所有缩放、学校电脑、真实课堂或付费模型质量验收。

扩展到相关导入/发送/选题窗口后，在未改动的0.1.90隔离副本重现四个旧测试失败：两个“不可预览WMF”夹具与现有矢量转换能力矛盾，一个图片上限测试仍写死旧13张，以及640×480发送图库高度超标。保持矢量转换能力，改用真正不支持的OLE类型做失败夹具（另有EMF成功用例）；上限用当前MAX_IMAGES+1而不改产品限额。图库缩小外边距和可滚动图注区，保留120像素主图、完整文字和确认按钮可见。原始基线比较日志保留。

扩展884项本地回归中，同源引用用例曾因测试助手连续两次保存同一Document跨过ZIP时间戳边界，生成了两个不同来源哈希而失败。改为复用同一份已保存DOCX字节，仍要求引用只在真实同源间改写；不放宽产品的来源身份判断。另补充仅核心原卷的旧组卷导出入口与文档审核使用同一题号投影，以及跨原试卷引用不得误连的回归。
