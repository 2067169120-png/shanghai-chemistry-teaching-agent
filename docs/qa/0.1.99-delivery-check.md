## 2. 三处新增连接

### 正式评分 → 原考试分析

从学生分析的作业批次进入“正式评分统计”。读取原学生/作答、教师正式评分和情况记录，按原题页内容、题号、满分和参考答案来源分组。不把不同试卷合并排名，不将暂存或模型建议计成教师分数。

待核对、缺页、未作答、尚未学到、图像难辨的记录从本次统计排除，正式原分数不删除；可读但时间不足的作答仍可能有有效教师评分。小题有各自有效人数，缺完整分项时不补整卷总分。此处只描述已匹配的评分单元，不保证覆盖原卷所有小问。生成后是快照，后续改分必须重新读取。

### 考试目标 → 真实题库 → 专用练习

考试“复练与复测”中明确原考试题目、学生、目标与日期，再选择当前真实来源支持的知识标签，进入已有选题中心。老师核对完整题面/公共材料，入篮后返回任务，明确勾选本任务要用的题。

预览使用该任务的有序子集，不把题篮里的其他备课题自动加入。原题身份与修订由原服务核对；学生/教师DOCX经原Office分页和核对后导出。不是API虚构题库ID，也不是已实现自动个性化排序。

### 实际复测 → 考试保存与报告

记录真实日期、状态、实得分/实际满分、观察依据和当次题目引用。未作答与资料不全不计0；完成结果要求明确有效分数、真实题目和依据。历史采用追加记录，当前概况显示最新录入的观察，原考试分数不改。保存重开与当前班级范围报告已有链路，不从不同试题分数差自动宣称进步。

## 4. 仍未闭合的实际问题

1. **目标覆盖未检查。** 合成任务目标同时写“动态平衡判据”和“平衡常数表达式”，但当前关联一题的输出只检查动态平衡判据，未覆盖后半目标。这不是题目丢失，而是尚缺目标—题目—评价对应检查。记入B03/D03/E03，后续要求逐目标显示所选题/证据，未覆盖可定位；不靠同一个K标签宣称全部掌握。
2. **任务题目仍依赖全局题篮。** 若已关联项被移出题篮或改变，重新预览会要求核对/重新关联。保存了引用不等于独立题集完成；X02后续应从稳定来源引用重建，不再要求老师长期把所有旧任务题留在题篮。
3. **复测保存不等于附件批改与长期档案。** 当前日期/得分是教师输入的事实记录，尚未挂接实际复测答卷附件；Excel临时学生身份未自动与原学生档案绑定，也没有跨卷量尺对齐。
4. **统计修正未自动传播。** 原批次继续改分后，已有考试快照、建议及任务不会自动同步。须重新读取；X03后续要提示哪些结果已过期。
5. **短窗口仍有密度成本。** 800×700记录区可读且可滚动，但顶部多组动作仍占相当高度。它不是已完成的高效率整天批改布局，原批次窗口的竖向空间问题也不因本次修正考试窗口而自动完成。
6. **导出时间/分值尚不等于合理作业量。** 本样例选择1题、分配2分，任务练习请求仍使用20分钟默认值，不能把这个组合称作已验证教学用时。后续提供任务用时/配分编辑并显示未知项，结合D03而非再建一套组卷器。
7. **全业务迁移未完成。** 备课ZIP仍不包含原Word/公众号题库、学生/考试/复测业务目录；HTML报告不能恢复这些对象。
