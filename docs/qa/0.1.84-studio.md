# 0.1.84 原生桌面验证说明

## 验证对象

8个主页面：首页、题库、组卷、学生分析、备课、教学模板、课堂工具、我的备课。另覆盖4个课堂工具标签、模板预览、导入资料、模型设置、题库进度、快捷入口与应用帮助。

测试使用Windows GitHub Actions、Python3.12和实际PySide6。原题库为空；备课草稿通过真实facade保存，内容是明确标注的合成演示，不含用户材料。课堂学号和统计为合成数据；没有读取、上传用户API配置或进行真实模型请求。

## 实际执行链

- 应用教学模板，保留原材料和图片引用；验证空白表单的默认课型/时间及重复应用不重复追加。
- 收藏模板，重建卡片，检查原题篮和草稿未被修改；搜索分类和收藏结果可见。
- 保存一份实际本机草稿，在“我的备课”找到该记录；另以回归测试指定较早草稿并验证打开正确版本。
- 点名一轮不重复；更改名单重置轮次；均衡分组保持全体成员且各组最多差1人。
- 倒计时按单调时钟推进，暂停、继续、重置；不使用刷新次数推算时间。
- 一级可逆A⇌B模型的封闭总量守恒、解析步长一致性、稳态正逆速率相等；实际播放/暂停并查看图形。
- 手动合成出口检测追加回备课资料，原材料保留，不自动保存或调用模型。
- 8主页面与各对话框打开、截图，核对窄窗口模板布局。
