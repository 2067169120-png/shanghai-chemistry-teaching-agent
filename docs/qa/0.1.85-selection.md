# 0.1.85 选题中心与真实分页

## 操作与数据边界

基于0.1.84，不修改题目正式身份或原文件。左侧同组OR、跨组AND使用原搜索引擎和个人题库筛选函数。原卷按最小作答单元匹配后保留完整主题；Word/图片来源的教材路径遵循已有父子校验。核心与个人题库分来源查询，没有虚构跨库总量。

选题篮读写既有DesktopStateStore。移除只移出篮、不删除题库。搜索、翻页、重新打开不清空篮。‘预览试卷排版’明确以当前篮全部项目和顺序为准；‘进入组卷编辑’继续旧组卷草稿。

分页复用MixedPaperService，实际DOCX转换PDF后显示像素。保留原冻结校验和学生/教师分离；新增本机Office/PDFium入口只解决开发机路径依赖，不做新的页面近似布局。使用什么工具渲染在产物中记录，缺少工具不生成占位。

## 验证范围

机器报告记录最终源提交、测试结果、Windows/Python/Qt和截图SHA。演示资料在临时目录由python-docx写出，经真实Word导入、现有标签编辑服务保存合成标签、在原生复选框中筛选，点击加入题篮、调整顺序，并点击预览走完整DOCX→Office→PDF→页图流程。所有题目、目录、来源类型均为合成测试，不含用户原题或密钥。

定向测试覆盖筛选布尔语义、答案不参与关键词、标签旧版本失效、持久题篮、指定顺序、窄窗口和预览接线。源文件解析成功不等于化学审核，全量真实资料仍在本机完成。

## 本轮接续复核

补充教材树展开状态与标签组手动收起的保持：搜索刷新不再重置阅读位置；切换来源时仍重新建立该来源菜单。已选题按钮使用纯中文状态，避免Windows字体缺失时显示方框。

新增三项原生回归：收起标签组后重新搜索、教材册/章展开路径重建、跨结果页选择并返回时保留原题篮和禁用重复加入。最终结果只记录最后一次Windows运行，不累加历史执行次数。
