# 独立复练题集：整理界面与过期回调防护

## 本轮范围

继续 PR #30，不另开平行功能分支。基线是 `fb008b848e047c5d19d367246795d4d2ef6e2217`，目标仍为 `feature/lesson-source-0.1.101`。PR #26 已关闭；PR #29 已接纳可靠性修复和维护分支只读检查。main应用源码及原v0.1.101 EXE、标签不修改。

本轮补齐“独立保存之后还能整理”的操作，不增加第二套题库、学生身份、生成平台或自由画布。

## 教师操作

在考试分析的“复练与复测”中，先从题篮勾选并保存题集，再点 **整理题集与目标**。窗口按题目顺序显示完整主题的标题及来源；可上移、下移、从本任务移除和恢复打开时的题目/顺序，也可编辑目标。移除只影响本任务的引用，不删除原题、全局题篮或复测/导出历史。至少保留一项，目标非空且不超过2000字。

点击取消不保存；保存失败时不关闭窗口，输入仍在。可以在全局题篮已清空后整理已有独立题集，操作不读取全局题篮。新增题目仍从题篮明确勾选，保存按钮说明会替换本任务当前选题，避免误以为自动追加。

保存成功后，实质题目顺序、内容或目标变动使旧预览确认失效，需再次核对学生/教师两版。旧文件和历史复测不删除。单纯重存相同内容不伪造新内容版本。

## 代码复核与防护

- 原候选导出完成回调将启动时的task副本整体回写。本轮改为校验考试/任务/内容版本后，向最新任务追加导出记录，保留操作期间已有的复测及其他历史；同一预览和同一产物的重复回调不重复登记。
- 确认结果返回时再次核对身份及当前预览，不只在点击时检查。切换任务、换考试或目标变化时拒绝旧回调。延迟测试是防护性模拟；通常同一窗口在任务期间会禁用相关操作。
- 操作前与回调阶段检查考试磁盘版本。另一窗口已经保存时要求重开核对；最后保存仍沿用原ExamStore的乐观并发校验。这不是跨进程数据库事务，不能消除检查与文件输出之间所有竞态，但不会静默覆盖考试记录。
- 保存失败恢复原followups及dirty标志。修改任务保留原列表位置，刷新不把选中任务跳回首项。跨考试记录与过期的expected副本均拒绝保存。
- 整理先验证原引用及哈希，不能把已经损坏的快照重新计算哈希当作修复。新增、重排与输出继续走原来源核验。

## UI与实际检查

窗口使用原生Qt控件和已有主题，明确区分整理、保存、取消及原题保管提醒。面板保留六项工作动作的自适应网格；复测入口与状态说明同排，避免窄窗再增加整行动作。新窗口以680与420逻辑像素宽度测试，控件均位于窗口内且列表高度不低于120；面板800×700场景记录区不低于150。不以请求的resize高度代替实际最小布局高度断言。

新增24项核心与11项Qt测试，覆盖调序/移除/取消/恢复、空目标、最后一题、保存失败、选中位置、磁盘冲突和延迟导出。原混合组卷、旧复练UI、README、发布安全回归继续保留。真实Office探针增加实际打开整理窗口、改序移除保存、重开、两版逐页确认导出，以及改目标后旧文件哈希不变。

## 保留的限制

保存的是来源引用，不是全题库/学生跨电脑备份；旧任务须重新勾选后才建立独立题集。新增题目暂不从整理窗口检索。真实Office样例仍为合成本地Word，复杂扫描和其他来源须独立验收。X03全链改分过期传播、X07题号身份映射、X09迁移、自由画布及新打包EXE没有因此完成。

原样例的考试知识标签与所选动态平衡目标并不一致，自动语义/目标覆盖不能从成功出卷推出；原20分钟默认时长也未因2分样例自动合理化。上述限制继续保留在原题集记录，不通过改截图隐藏。

本轮没有发布新版本，没有处理真实学生或用户教材，没有网络模型请求。源码接纳不等于已发布试用包增加了新按钮。
