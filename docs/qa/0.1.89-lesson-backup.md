# 0.1.89 备课备份：实现与验收边界

在现有个人状态上导出明确子集：只有preparation草稿进入备份，其他草稿可能属于学生分析等业务，不直接复制整份目录。备份清单区分实际打包文件和外部引用。图片和成品默认不勾选；教师手动选定后只读取登记的相对路径，不全盘扫描。

恢复只向新目录写入。文件列表、相对路径、大小、SHA256、JSON版本和任务状态先校验；恢复标识最后写入，未完成目录不能通过“打开独立副本”入口。相同版本/身份不需要重建；已存在目录一律不合并、不覆盖。模型配置、学生业务目录和可执行程序不在支持路径中。

备课内容可能由教师手动包含个人信息；这是本地ZIP，不提供密码或自动脱敏。哈希证明文件一致，不证明资料可信、化学正确或档案已完成审校。不要打开不明来源的备份及其成品。

本版补回仅适用备课内容哈希图片库。Word/公众号导入资料及其标签的可迁移备份、外部Word重新关联仍留在A08后续任务。题篮保存引用及已有摘要，而不是完整原题。

回归包含正常恢复、原文件不变、原图字节一致、已结束任务成品、非备课/模型目录排除、501份草稿、坏ZIP、过期确认、路径越界、取消、写入失败和原图错误拒绝。Windows源代码和同一发行EXE另点击完整备份流程，并以生产渲染器从恢复的规范候选再次导出。具体执行数量、SHA与截图以本版机器报告为准；不累加重叠历史测试。

首轮Windows回归389项通过，随后全流程检查因合成恢复目录位于源码内，触发现有模型设置目录的分离约束。已改为真正的外部临时恢复目录，并增加桌面提前提示与零写入回归；未放宽原有模型配置的目录限制。最终计数以机器报告为准，首轮不重复累加。
