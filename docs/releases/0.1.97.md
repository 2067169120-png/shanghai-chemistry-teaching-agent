# 0.1.97 · 作业批次与逐人复核

学生分析增加“作业批次”：教师明确选择已有作答，建立/编辑批次，逐人切换并在原图旁复核评分。每人每批只选一份，不根据文件名猜身份，不自动进行批量模型分析。

批次切换/返回时暂存未记录的分数、理由和状态，重开可继续；暂存不等于正式评分。主动清除只影响未记录输入。正式评分、诊断和原AI稿分别保留。新增待核对、资料缺页、未作答、尚未学到、时间不足、图像难辨等教师情况记录，不自动将缺失当0分，也不输出班级均分/排名。

README本次为完整功能介绍，覆盖八主页面、导入、模型设置、备份和常见问题，附历史标版与本版实际截图；不是只列新功能的日志。旧指南完整归档。

同一代码经Windows定向回归与实际便携EXE检查后交付。试用包未签名，完整解压运行EXE，无需Python，不单独移动EXE或_internal；实际DOCX分页仍需本机LibreOffice或Word。程序不附教材、原题库、学生资料、密钥、Office或字体文件。

当前批次针对已有分析的复核，不含批量上传/模型循环、班级正式成绩汇总、复测回写或学生数据迁移。暂存不是每键自动恢复，突然退出前尚未暂存的最新输入仍可能丢失。现有备课ZIP仍排除学生目录。
