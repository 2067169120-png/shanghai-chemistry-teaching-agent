# 0.1.87 · Windows 原生试用版

这是前一轮0.1.87候选的验收与交付版本，不是另一个平行应用。包含0.1.83—0.1.86的桌面、题库、组卷、课堂工具、备课恢复和历史搜索改进。

## 本版内容

设置页将基础连接和高级预算分开；隐藏预算不会丢失。图片发送许可与实际识图证据分开，不把文字联通当作多模态验收。新增本机运行身份、依赖、目录及Office安装发现检查。55项随软件分发的资源有明确清单。

本版提供Windows x64便携包。完整解压后双击“沪上化学智研台.exe”，不需另装Python；不要单独移动EXE或_internal目录。备课、题篮等仍保存在当前Windows用户的本地应用数据目录，不随程序目录迁移。程序不包含原教材、教师题库、学生资料或API密钥。

## 验证与边界

发行流程对同一代码提交执行源码回归、设置交互和独立EXE检查，再收集实际截图。EXE复制到与源码无关的目录，移除开发Python/工作区搜索环境后开关窗口，打开8页、保存合成草稿、生成5页PPTX与DOCX，并用Office转换获得2页教案PDF。不是仅构建成功就宣称运行通过。

测试使用合成教学材料，不调用真实模型。PPT预览仍是共享布局渲染，未完成Office对实际PPTX的逐页视觉一致性验证。独立运行目录验证不等于在所有Windows电脑上完整验收；原资料规模、多显示器、Windows缩放和课堂效果仍需实际试用。

程序未签名；请核对本仓库Release来源与SHA256，不要关闭系统防护。真实DOCX分页依赖本机LibreOffice或Microsoft Word，这些工具不随包分发。完整字体文件不随包分发，不同机器的字体可能影响分页。

Release内提供便携程序ZIP、含README截图的源码ZIP、Windows验收证据ZIP、校验清单和发行清单。发行清单分别记录实际受测/打包源码提交与随后只增补截图和报告的标签提交。版本标签建立后不移动；后续程序变更使用新版本。
