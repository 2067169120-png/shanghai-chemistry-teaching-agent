# 0.1.96 · 原作答与评分同屏

“学生分析”打开一份已有作答后，可进入“打开作答与评分（同屏批改）”。题目导航、原始整页和教师评分同屏，支持原题/参考答案切换、放大和证据框定位。AI原建议不改写，新评分留空，教师分数及理由沿用原独立记录。诊断与评分分开，改分后旧诊断需重核。

同窗口切题保留未记录输入；保存一题不丢另一题。失败保留输入，刷新后核对再提交。800×700隐藏左侧目录但保留题目下拉、原图、评分和固定记录按钮。本版处理一个学生一份已有作答，不等于完整班级批改系统；未记录输入不是自动恢复稿。

同一源码与发行EXE均以两名合成学生验证本地原图读取、改分、诊断、重开及另一学生不受影响。分析初稿由本地固定传输夹具产生，没有真实API调用或真实学生数据；这不是化学评分质量或识别准确率验收。最终测试数量见对应机器报告，不累加子集。

Release附Windows x64便携ZIP、源码、嵌图指南、Windows记录和校验清单。完整解压后双击EXE，无需另装Python，不单独移动_internal。未签名预发布，不关闭系统防护。原题库、学生作答、密钥、Office及字体文件均不随包提供；真实DOCX分页需要本机Office工具。

原有备课备份不含学生业务目录。班级批次、复测、整库迁移和实际PPTX视觉一致性等仍待完成。main和历史PR不自动合并；标签建立后不移动。
