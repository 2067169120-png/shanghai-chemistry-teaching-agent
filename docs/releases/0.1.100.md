# 0.1.100 · 教学环节与同源教案/PPT/学习单

本批回到备课主流程：在原备课草稿中安排环节、目标、教师活动、学生任务、预期产出、评价与用时，支持增删、调序、撤销/重做。只在教师确认任务与证据后显示目标明确关联，不把未安排目标或同类知识标签当成已经覆盖。

同一设计本地生成教案DOCX、可编辑PPTX与学习单DOCX；图片/材料/教师答案可锁定，学生正文与教师备注区分。修改后标记旧成品，再生成保留历史版本并选中最新稿；可整套导出独立副本。保存和恢复沿用现有备课服务。

实际PPTX经本机LibreOffice Impress转换PDF逐页核对，不以快速结构PNG替代；不是全部PowerPoint版本的视觉一致性保证。图文指南完整保留既有八个页面和考试/批次/复练工作流，新增教学环节步骤及同轮截图。

本版是人工可编辑、可保存且可输出的第一批设计闭环。既有API生成入口保留，但模型稿尚未自动导入节点、AI限定节点改写及复杂Word公式/表格无损绑定尚未完成。节点元数据随草稿保留，新三类成品目录尚未纳入旧备课ZIP，需要另存导出文件。原题库/学生/考试全业务迁移仍未完成。

Windows定向回归、实际源码窗口和同一EXE独立目录检查对应同一受测提交，见发行清单与QA。合成材料不代表真实课堂效果或AI准确率；没有真实模型请求和用户题库重导。程序未签名，完整解压运行EXE；无需另装Python，实际文档分页需本机Office工具，实际PPTX预览目前需LibreOffice。不附字体文件、教材、学生原页或密钥。
