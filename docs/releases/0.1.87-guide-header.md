## 启动：便携程序与源码二选一

### 教师试用便携程序

从本版Release下载 `ShanghaiChem-0.1.87-Windows-x64.zip`，**完整解压**，双击目录内的 **`沪上化学智研台.exe`**。不要在ZIP里直接启动，不要只复制EXE，不要删除旁边的`_internal`目录。窗口状态栏应显示 **v0.1.87 / 打包版**。不需另装Python；程序本身不包括Microsoft Office或LibreOffice。

程序未签名。请核对仓库发布来源和`SHA256SUMS.txt`，不要关闭Windows防护或跳过可疑文件警告。当前验证平台是Windows Server 2025 x64；尚未逐一验证全部Windows10/11配置、学校管控电脑或不同缩放。

### 开发者运行源码

源码版在含README的目录执行以下命令，随后双击 **`启动源码桌面版.cmd`**。状态栏应显示 **v0.1.87 / 源码版**。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r runtime\deeptutor_shchem\desktop_requirements.txt
```

已有Git目录先保存未提交修改，再执行 `git fetch origin` 和 `git switch feature/desktop-onboarding-0.1.87`。不强制重置；旧VBS仍可能启动本机旧EXE。源码版无法启动时可双击 **`检查运行环境.cmd`**。

### 资料和升级

个人设置、草稿、题篮及恢复副本继续放在 `%LOCALAPPDATA%\ShanghaiChem\DesktopWorkbench`，不随程序目录变更而搬迁。关闭旧版本后再运行新版本；替换程序目录不是删除个人资料。程序不含你的教材、题库、原图、学生作答或密钥。

源码旁的`sh-chem-db`仍按原规则使用；没有原库时建立个人空目录。**便携包不会自动复制另一源码目录旁的题库。** 原资料可继续使用原源码环境，或以`SHCHEM_WORKSPACE_ROOT`明确关联原工作区；不要把题库复制进`_internal`。恢复副本保留图片引用，不是原图备份，A08完整备份/迁移仍待实施。

## 本版设置与本机检查

![基础连接设置（0.1.87实际Windows窗口）](docs/screenshots/v0.1.87/settings-basic.png)

先填服务商、Base URL、实际模型名、密钥和接口格式。保存仅修改本机配置；点击“测试连接”才会确认并发送固定短文本。修改了配置但未重测时，旧成功结果不作为当前连接已验证的证明。

![高级预算展开（0.1.87）](docs/screenshots/v0.1.87/settings-advanced.png)

高级预算默认收起，已有值仍保留；输入/输出预算可留空或按需修改。错误输入会展开高级区以便纠正。预算不是厂商容量保证，图片的本地估算不是真实计费值。图片发送许可与模型看图能力是两回事，本轮没有发起真实多模态验证。

![较窄设置窗口（0.1.87）](docs/screenshots/v0.1.87/settings-compact.png)

![本机检查（0.1.87）](docs/screenshots/v0.1.87/environment.png)

本机检查可从状态栏、设置和快捷搜索打开；结果分别说明版本身份、Qt/PDF/Word/PPT组件、图标资源、个人目录写入和Office安装发现。检测不读取密钥、不扫描题目正文、不发网络请求。可复制或保存JSON。**发现Office不等于转换成功，空题库也不等于应用无法运行。** 真正分页需本机LibreOffice或Windows Microsoft Word。
