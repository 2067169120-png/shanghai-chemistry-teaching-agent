# 0.1.92 · 中文字体与显示修复

修复应用、样式和自绘文字各自选择字体的分散逻辑：按本机实际可用且覆盖中文样例的字体选择，Windows优先微软雅黑；正文11磅，小字至少9.5磅，标题适度加粗。新增“本机检查→中文界面字体”及化学符号样例，显示实际字形和当前窗口倍率。

源码与发行EXE在Windows原生Qt后端测试1.0/1.25/1.5倍率，记录实际字形与控件位置。这是Qt缩放模拟，不是所有Windows设置、多显示器、用户设备的全面验收。结果数量与受测提交以本版机器报告及RELEASE-MANIFEST.json为准。

原题号、备份、草稿和导出服务继续沿用。本版没有下载或分发字体文件，不改变原题图片、Word文件或已生成课件；修复界面字体不等于修复模糊图片。扫描图片内部旧题号替换和完整题库迁移仍待后续处理。

完整解压Windows x64 ZIP，运行沪上化学智研台.exe，无需另装Python，不单独移动EXE或_internal。程序未签名，请核对发布来源和SHA256，不关闭系统防护。真实DOCX分页仍需本机LibreOffice或Microsoft Word。没有真实API调用、资料重导或教学效果验证。
