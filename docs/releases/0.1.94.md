# 0.1.94 · 题号位置复用与答案分页

混合组卷的“调整图片题号后预览…”新增记住此图位置、载入位置、忘记位置。只保存图像身份与坐标，不保存上一卷号码。对单一Word印刷题中的图，从当前组卷顺序给出新号建议，教师核对后添加；共享或歧义来源仍手工确认。换序重开可以复用框选，不会套用旧卷号码。

修复简短答案首段与首张图的跨页分离；生成的答案标题跟随开头内容，长答案和表格仍可正常分页。原图、文字、公式、题篮身份和已保存文件不改。程序沿用0.1.93中文字体与符号修复。

本版Windows同一代码运行回归、实际框选保存/重开/换序、两版DOCX/PDF、字体倍率与独立EXE验证；结果与来源提交见Release清单及README。用的是合成资料，不代表用户全题库/真实课堂或所有Windows设备验收。未做真实模型请求。

仍为静态PNG/JPEG/BMP的白底数字手工核对，不是OCR；同图逐实例不同号、复杂源页和引用目标自动关联尚未完成。位置记录保存在当前个人工作区，尚未包含进旧备课备份。完整Word/公众号题库迁移仍在Issue #9。

完整解压便携ZIP后运行沪上化学智研台.exe，不单独移动EXE/_internal，不需另装Python。程序未签名，请核对来源和SHA256，不关闭系统防护；实际DOCX分页需本机LibreOffice或Microsoft Word。无字体文件、用户题库或API密钥随包分发。
