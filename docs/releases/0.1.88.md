# 0.1.88 · 作品整理与Windows便携试用版

基于v0.1.87，新增“我的备课”当前作品、已归档和回收站。作品名称与原课题分别保留，新名称和原课题均可搜索。草稿及已结束的生成任务可重命名、归档、移入回收站、还原到原范围；活动任务不会被隐藏或自动取消。

整理信息只写入原个人状态，不改草稿正文、任务文件、原图、题篮、未保存编辑或已导出的PPTX/DOCX。本版没有永久删除；回收站不会释放磁盘空间，不能代替备份。旧版本不理解分类，降级可能重新显示隐藏记录，但原件从未删除。

Windows便携包完整解压后运行“沪上化学智研台.exe”，不用另装Python，不要单独移动EXE或_internal。真实DOCX分页仍需要本机LibreOffice或Microsoft Word。原题库和个人资料不随软件包分发，不包含模型密钥。

本版为未签名预发布。校验包与来源，不关闭系统防护。验收使用隔离合成资料，包括原生界面点击、独立EXE运行、既有5页PPTX与2页教案PDF生成；具体源码、数量及范围见README和机器报告。没有真实模型调用、用户全量题库或完整课堂质量验收；Windows10/11各种硬件与缩放仍需本机试用。

Release包含便携程序、源码、图文指南、测试证据、发行清单与SHA256SUMS。分别记录受测/打包提交和仅补截图文档的发行提交，不移动旧版本标签。A08备份与重新关联为下一批。
