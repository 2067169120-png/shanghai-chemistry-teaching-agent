# 0.1.93 · 中文显示与扫描题号调整

本版承接0.1.92未发布候选的字体修复，补回化学符号回退，避免重复全局样式刷新，并调整较大字体下的发送确认留白。0.1.92没有补造Release。

新增混合组卷“调整图片题号后预览…”：手工框选旧号、填写本卷号，支持撤销、清除、移除和原图对照，再通过原有分页服务生成学生/教师两版DOCX/PDF。原图和框外解码像素不改；答案专属图不混入学生版。当前为白底数字替换，仅支持静态PNG/JPEG/BMP，不自动识别旧号、关联题序或修复彩色背景。改变题序或重新生成后重新核对，框选不持久写入题库。

Windows x64便携包完整解压后运行沪上化学智研台.exe，无需另装Python，不单独移动EXE或_internal。程序未签名，请核对发布来源和SHA256，不关闭系统防护。真实DOCX分页依赖本机LibreOffice或Microsoft Word。没有分发字体文件、原题库、学生资料或API密钥。

源代码与同一EXE的测试、三档Qt倍率、实际导入至两版PDF和新窗口截图见README及机器报告。Qt倍率模拟不等于真实Windows系统缩放、多屏或全部设备验收；合成资料不代替化学质量和全库验收。无真实模型调用。A08全题库迁移、完整节点编辑和实际PPTX的Office视觉一致性仍未完成。
