# 0.1.89 · 备课备份与独立恢复 Windows试用版

基于0.1.88，新增“我的备课→备份与恢复”和Ctrl+K入口。备课草稿（当前/归档/回收站）、分类、题篮身份和恢复表单可存为校验ZIP；本地备课图片及已结束任务/返回稿/成品由教师明确勾选。

恢复先检查清单和文件哈希，再创建独立个人目录，不覆盖/合并当前资料。独立恢复窗口有明确标题，没有原模型配置，不会自动发起或恢复模型请求。缺失备课图片可按相同内容哈希、尺寸与格式补回，不按同名替换。

**本版不是全工作台备份。** 原Word/公众号题库、其他业务草稿、学生档案、模型配置、密钥不包含；题篮保留引用不代表原题已打包。正文中自行录入的信息不会自动脱敏，ZIP未加密，请妥善保管。单文件128MB、总计2GB/2万文件，图片沿用10MB限制。

便携包完整解压后运行EXE，无需另装Python；不要移动单独EXE或删除_internal。未签名预发布，请核对发布来源及SHA256，不关闭系统防护。真实DOCX分页仍依赖本机LibreOffice或Microsoft Word。

Windows源码及同一独立EXE的测试、备份恢复和输出结果记录在QA附件。测试使用合成资料，无真实API调用；并非所有Windows配置、真实大题库和课堂质量验收。实际PPTX的Office视觉一致性仍未完成。

每版保留独立分支、PR、注释标签、README截图、CHANGELOG、发行清单和校验文件。main和历史标签不自动移动。A08的原Word/全题库迁移与重新关联继续拆分推进，不计入本版完成范围。
