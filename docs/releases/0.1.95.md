# 0.1.95 · 题目加载与导入衔接

本版优化本地个人题库：目录索引复用、翻页查询缓存、取消过期查询、Word多图合并读取。首开仍有源文件与索引成本，不用局部基准承诺每台机器全局加速。

保留原生Windows/PySide6。新增来源选择记忆、空结果个人库入口、导入退出刷新及“复制加载记录”；通用文件入口置于旧资料包之前。备课备份现在包含已存题号区域，不含对应原题图；新版本兼容旧ZIP，新扩展需支持版本恢复。

同一代码执行Windows定向回归、合成题目界面与备份流程，并复制实际便携EXE到独立目录运行。研究作者老三的AI充电站公开工作流与Coze/Docling等项目，但本版没有新增外部服务、作者收费插件或模型请求。

Release提供便携包、源码、Windows证据、嵌图指南、工作流研究、发行清单及SHA256。程序未签名，完整解压后运行EXE，不单独移动_internal；无需另装Python。实际DOCX分页需要本机Office工具。不附原题库、教材、学生资料、密钥或字体文件。

全量原Word/公众号迁移、批量班级批改闭环、完整教学节点编辑和实际PPTX视觉兼容仍待完成。合成样例不代表真实课堂/全校设备验收；旧标签不移动，main及历史PR不自动合并。
