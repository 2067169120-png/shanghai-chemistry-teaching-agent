# 0.1.98 · 考试数据分析与API讲评

学生分析新增“考试分析（Excel）”，Ctrl+K也可搜索。普通xlsx支持工作表/表头/列映射，只有总分可看分布，有明确小题满分和知识点可看逐题、主知识点和学生热力表。空白与缺考不记0分，异常/冲突显示源行。统计全部本地完成。

支持附试卷DOCX/PDF/图片，API生成班级讲评、分层策略和复测建议；匿名汇总默认，逐人明细与试卷图另外勾选并确认。文本API不能被当作视觉API，结构化返回不改写图表数字。保存本机快照、导出离线HTML、追加讲评到备课。附合成Excel示例及图表样例。

源码与同一Windows便携EXE以合成数据、固定传输执行检查；不代表真实模型建议质量或课堂提分。完整README包含既有八页全部功能及本版截图，不用更新日志替代操作手册。版本标签不移动，main不自动合并。

程序未签名，完整解压后运行EXE，无需另装Python；实际原组卷分页仍需本机Office。不附题库/教材/学生原件/密钥/字体。新考试快照未纳入旧备课备份；跨考试趋势、批次自动汇总、题库推荐和复测回写仍待完成。
