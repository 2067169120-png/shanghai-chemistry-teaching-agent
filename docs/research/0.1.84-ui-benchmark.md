# 0.1.84：飞象老师界面参考与功能取舍

核对日期：2026-09-14。目标是面向上海高中化学教师的原生Windows日常工作，不是复制商业网站，也不把看过宣传页等同于登录实测全部功能。

## 公开依据及阅读边界

- [飞象老师官网](https://www.feixianglaoshi.com/)和[公开入口](https://www.feixianglaoshi.com/staging/)的索引展示教学动画、教学游戏和互动课件分类。主站使用前端加载，本轮没有登录个人账号或完整验证其每个工具。
- [飞象老师官方AI工作坊](https://www.feixianglaoshi.com/AIworkshop/2026-fall-opening-class/)公开页面展示从教学想法到课堂作品、教学动画、练习游戏和教学评价等组织方式。阅读网页正文，没有观看全部课程、下载资源包或复制其教学案例。
- [极客公园公开界面报道](https://www.geekpark.net/news/357513)用于观察公开产品截图中的导航、输入区和作品卡片。新闻图片不是本软件的设计资产，不随代码上传。

这些资料支持“任务先行、作品可预览、课堂交互、结果回到教学”的产品方向；不能据此断言飞象每一项具体按钮、算法或课堂工具已做过真实性能测试。

## 设计对照

| 对照方向 | 原工作台缺口 | 本版实际落点 | 保留边界 |
| --- | --- | --- | --- |
| 从一句教学想法开始 | 首页主要是状态和导航，缺少课题起点 | 课题输入、模板选择、完整预览、带入原备课表单 | 不直接把一句话冒充已生成成品；生成仍由原流程确认 |
| 清晰的作品/场景卡片 | 多种组织建议分散在表单中 | 6种原创教学结构卡片、分类、搜索、收藏 | 不是获奖PPT原件或飞象原模板 |
| 课堂交互内容 | 原生界面缺少即开即用的互动工具页 | 倒计时、点名分组、动态平衡、出口检测 | 这些是针对本地教师流程的具体实现，不宣称逐项复制飞象对应工具 |
| 交互模型支持学科解释 | 多为静态题图和备课材料 | A⇌B参数调整、浓度和正逆速率变化 | 固定封闭一级反应示意，不是AI生成任意化学动画或真实实验数据 |
| 找回并继续编辑 | 草稿与生成记录分散 | 我的备课统一查询原有两个来源 | 本机最近记录；不是云端作品社区 |
| 教学反馈形成下一次输入 | 临时课堂统计难以带入备课 | 教师手动反馈追加到现有资料区 | 不伪称自动采集、实时投票或长期掌握度计算 |
| 导航和操作一致性 | 页面视觉层级不统一 | 一套原生QSS、矢量图标、Ctrl+K入口与F1帮助 | 不引入第二套Web前端或复制商标 |

## 为什么不在本轮堆满所有差异功能

任意AI交互游戏生成、语音入口、联网作品社区、跨设备同步、学生端实时数据，都需要各自完整的数据、运行和教学验证；放几个无法工作的入口不能缩小实际差距。本轮选择已经能接入原表单、状态与草稿服务的功能，实际在Windows运行后截图。后续仍优先完善真实材料与教案/PPT输出，而不是偏离学科和桌面主线。

## 视觉原则

左侧保留稳定任务，顶部提供搜索、帮助和资料导入；主区使用大标题、清晰输入和留白，主操作绿色、次操作白色，不把所有按钮都做成同等强调。教学模板与课堂工具使用原生控件，可键盘操作。学生资料或真实原题不用于公共界面演示。

18张本版图来自实际PySide6窗口，不是AI生图或网页替代。首轮截图暴露旧模板卡片残留与曲线意外填充，已修复并补测试；最终截图的源提交、操作系统与哈希记入QA报告。知识蒸馏和真实题库由用户后续本地推进，本轮不增加相关完成数量。
