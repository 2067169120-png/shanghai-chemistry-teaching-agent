## 推荐使用顺序

0.1.53已将46份讲义索引接入原生备课页的“查找已导入的原教案”：按原文件SHA及名称绑定，支持检索知识、方法和易错点，查看后打开对应的完整原文与图片。0.1.65接入上述10条新增索引，并显示两专题的教材章节与页码关联。0.1.66进一步允许在选段预览时附加对应知识与方法，原教案保持主要内容。没有索引的52份原资料仍保留列表入口。摘要不直接当作教材原句或生成指令；本轮更新的是派生索引，原教材、原教案及提取缓存未改。

使用入口为原Word阅读窗口“选段与备课”里的“同时带入知识总结与解题方法”。46条来源记录带有 `source_preview_revision`，只有匹配当前原生提取版本、且一条知识的全部来源区块均在选段内才附上。教材链接以 `lecture_block_indices` 绑定具体讲义段落；不因整份讲义归属而扩大教材范围。0.1.68增加可选字段 `teaching_flow`，原教案检索和选段参考均可显示“讲练与笔记”；旧索引不含此字段仍可用，格式异常则不采用对应索引。确认时重新编译并核对知识索引与教材原件，来源变化后旧预览失效。题目追加备课会附带当前有效教学标签及原状态，便于后续安排例题用途；仍不是API自动选题或课堂质量验收。

0.1.66只打通既有提炼到备课参考的交接：两份真实讲义的明确仅文字参考分别带入7/2条讲义条目与6/4条教材候选，三个原题样本的标签保留，不是新增知识量。0.1.68的钠、铁第1课时连续跨度超过20,000字；0.1.69新增显式多段清单，分别选择知识段和完整例题后，两者的仅文字交接均通过，未选择的中间123/239个区块不带入。铁带图读出7个不同资产，钠区块59仍有旧对象问题，带图确认不放行。新增原子结构两课时精确多段的仅文字参考分别为7,015/7,146字，带图检查分别有1/5个可读资产，无图片或一般参考问题；没有据此生成最终PPT或完成课堂验收。

老师在“选段与备课”勾选“合并多个分散段落”，逐段点击“加入当前段”，核对清单后生成预览，再确认追加。知识条目的全部依据可分布在不同选段，但仍须全部选入；未选文字和原图不补写。较窄教材范围没有完整匹配现有候选时只显示页码线索，不放宽到整章，关联页码也不等于已附原页图片。容量、旧对象与全讲图文整理仍需继续处理。

先按本次授课的知识点找到对应教案，再阅读其完整正文、例题、答案和图片。摘要只帮助定位前置知识、常考条件与方法，不替换原教案，也不自动变成教材原句。用于PPT时保留原教案的概念关系和必要条件，结合老师选定课时安排讲解、练习与总结；学生笔记页应有清楚的知识表达或表格，而不是只有目录式标题。

每条讲义摘要以 `source_sha256` 绑定原件，以 `block_indices` 指向原生段落/表格；区块号不是纸面页码。教材条目中的 `pdf_pages` 是PDF文件页序，不一定等于印刷页码。SHA或原件发生变化后，须重新建立对应关系。

所有 `human_reviewed` 保持false，既有教材的候选/生成/发布字段原样保留；本目录的授权是简明改述索引的版本管理，不是原文件再分发授权或正式题库放行。未知的原题年份、地区、考试类型不能从文件名猜测。原资料的问题与软件提取缺口应分开处理。

平台课件卡只记录逐页观察所得的教学顺序、表格/例题的页码和本项目的适配建议。课程包入口与实际课件预览入口同时保留；未取得原文件时SHA保持未知，课件页码也不冒充教材页码。截图、访问过程记录和辅助规范文件留在本机，不进入公开知识包。

2026-09-12 新增[核外电子排布的表示方法](courseware/smartedu/electron-configuration-design-card.md)：从孙卫中老师的对应课程包读完29页课件，并读完教学设计3页、学习任务单2页和课后练习4页的正文。源码已加入“同一对象的表示互译、独立练习、笔记比较表”的可编辑建议；不替换原Word教案，不照抄平台题图。原0.1.60-r2桌面包不包含本次新增建议。

## 本地复核

在配置好本机原始资料及缓存的工作区，运行 `staging/coordination/deeptutor_gateway/scripts/validate_lecture_knowledge.py` 可核对46份来源SHA、摘要区块引用和已绑定的提取版本；`verify_analysis_native_materials.py` 核对98份归档原Word、原生区块与图像字节。两者不调用模型，不改写原件。`extend_lecture_knowledge.py` 默认只预演，核验原文区块、教材目录及对应PDF的SHA后才允许显式合入上述扩展；`--bind-source-revisions`仅补缺失版本，不自动替换已变化的旧版本。重复合入为零新增。原始资料不在Git中，纯克隆仓库无法执行真实来源复核。
